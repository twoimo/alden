# Saved subjects and reference lists in the overview

The overview previously filled eight slots with two saved subjects, source claims, long video/post titles and a room name. All eight received the same subject styling. The display now prefers existing subjects and short, explicitly linked reference lists. Leaf titles retain their title role and appear after zooming in when headings exist. A graph without saved headings keeps its title fallback. Chat-room names no longer fill overview caption slots; their nodes and selection remain available.

Reference lists have an angular teal label with a visible `목록` badge and a tooltip distinguishing saved references from verified body content. Admission requires a versioned hub/index, at least two distinct currently valid visible links to versioned nodes in the same source target, a descriptive saved label and no withdrawal. Generic routing buckets and internal identifiers are excluded. NFC/whitespace comparison deduplicates displayed captions only. No identity, original label, relation, source permission, content-evidence state or layout algorithm changes.
