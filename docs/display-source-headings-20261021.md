# Source content lines in graph titles

A blank stored title could make the graph display a legacy export's `- 링크: URL` or reaction-counter header. The popup retained the original source, but the graph's visible title did not describe the content. An actual preselected lookup probe exposed four such sources; changing title ranking alone did not repair these display headings.

The existing fallback now skips an entire URL/link field and the exact observed `반응: 좋아요 … · 답글 … · 리포스트 …` header, then selects a literal body line under the existing Korean/English length preferences. A saved nonblank title still wins. Sentences that discuss links or numerical results remain eligible. Header-only material gets no invented title and keeps its existing identity fallback. The helper returns once the first qualifying long Korean line is known; short Korean/English fallback priority is preserved.
