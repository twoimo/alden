# Alden OpenCodex 모델 선택과 통합 그래프 상단

사용자의2026-10-08 요청으로 대화 LLM은 기존 OpenCodex 라우팅을 명시적으로 선택할 수 있게 한다. 기본 선택은 `agy/gemini-3.8-flash`의 `high`이며 실제 카탈로그의 같은 모델 ID는 `google-antigravity/gemini-3.8-flash`이다. Codex·Aside의 전역 모델 설정이나 OpenCodex 서비스 기본값은 바꾸지 않는다. 임베딩·STT·TTS는 로컬 경로를 유지한다.

카탈로그는 현재 데스크톱 라우터의 `127.0.0.1:10101/v1/models`를 읽는다. 확인 시17개 항목이 있으며 원본에 있는 모델 ID, 표시 이름, 제공자, 사고 수준만 사용한다. `model_messages`와 실행 지시는 버린다. 모델별 연결·실행·메모리·최근 실제 응답·쿼터 상태를 구분한다. 음성 전용 모델은 목록에 표시하지만 대화용 선택은 비활성화한다. 목록에 있다는 이유로 모든 모델의 추론 성공을 주장하지 않는다.

로컬 선택은 실제 localhost 모델 목록의 loaded/ready와 fresh macOS 메모리 관측을 요구한다. 추가 작업 공간2GiB, physical free128MiB와 normal pressure를 정책상 요구하며 상태를 읽을 수 없으면 사용 가능으로 간주하지 않는다. 새 가중치를 자동으로 올리거나 다른 앱·모델을 종료하지 않는다. 연결됨은 라우터·카탈로그 확인, 사용 가능은 최근5분의 실제 성공 확인이다.

자동 선택은 응답 시작 전에 현재 상태로 결정한다. 최근 실제 성공과 메모리 여유가 확인된 로컬 Qwen27B 또는 요청한 Gemini Flash를 사용한다. Astra/Pro/Opus로 자동 승격하지 않는다. 이미 요청을 시작한 뒤 실패하면 다른 모델로 재전송하지 않는다. 자동 선택은 사용자가 직접 켜며 초기 설정은 요청한 GeminiHigh 수동 선택이다.

선택은 원자적으로 저장하고 읽어서 확인한다. 음성은 각 턴의 모델·사고 수준·설정 SHA를 고정한다. OpenCodex Responses 응답에서 assistant output_text만 사용하며 reasoning, 잘못된 모델, 불완전한 종료는 출력으로 채택하지 않는다. 취소 시 앱의 소켓·결과 소비를 중단한다. 라우터 이후 원격 추론의 완전한 서버 측 취소는 별도 검증 항목이다.

기존 고정 자동답변 런타임이 클라우드 선택을 버리고 로컬로 돌아가던 경로도 수정했다. 정상 준비 도구로 호환 런타임을 별도 디렉터리에 생성하며 기존 선택자·CLI·설정과 대기열을 유지한다. 초기 staging은 enrollment를 전환하지 않는다. 실제 전환은 설치·CI와 검증 후 수행한다.

그래프 제목·범위·프로젝트·검색·필터·목록은 상단 한 줄에 모았다. 긴 표시 범위와 색상 안내는 정보 버튼으로 옮겼다. 좁은 창에서도 한 줄이며 상세 정보를 삭제하지 않는다. 모델 메뉴는 창 아래쪽에서 위로 열고 자체 스크롤한다.

UI395, Python route/voice19와worker42, Rust108/Clippy가 통과했다. 기본·최소 native 화면과 모델 메뉴의 QA를 수행했다. 작은 창에서 위쪽 메뉴가 잘리던 문제를 수정해 실제 남은 높이로 제한했다. 설치·기본값·활성 런타임 되읽기는 진행 중이다. 단일 probe를 일반 성능·품질·쿼터 절감으로 해석하지 않는다.
