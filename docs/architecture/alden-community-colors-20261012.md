# Current computed communities in0.3.81

The R/S solver previously calculated communities but the overview renderer used
one connected-node colour for most nodes. The display now consumes the current
completed checkpoint's membership labels and shows four major groups in distinct
colours. The remaining nodes share an aggregate `기타` category; that category
does not confer common membership, identity, truth or a new source relation.

`community-snapshot.ts` validates a complete one-to-one batch of current IDs
before applying any colour. Missing, duplicate, unknown or malformed labels
clear group colours and hide the group legend, while valid coordinate updates
continue. Group counts are computed only from the currently displayed scope.
Ties use stable cluster-ID order. Surviving major groups retain one of four
bounded palette slots. Local selection and actual relation-distance colours
retain priority. Rebuilds may reuse metadata only when the completed input key
matches current nodes, versions, R/S, pins and relation validity.

The metadata is display geometry, rather than an entity merge or stored knowledge
group. It uses neither source names nor node text to infer topics. The original
solver, budgets, stored IDs, directed source facts, positions, glyph radius and
existing GPU allocations remain. New colours and legend counts require no
per-frame pair search or model inference.

## Visible temporal boundaries

An independent regression reproduced reuse of a same-ID checkpoint after its
unchanged relation reached `validTo`. The signature now includes the current
validity of each visible relation. One owned timer rebuilds the existing view at
the next known boundary; it stops when hidden/stopped and resumes at current time.
The timer emits no reads, voice or activity receipts, preserves the user's camera
and does not mutate source facts. Starts are inclusive and ends exclusive.

This is scoped to already-authorized visible relations. Future rows omitted by
an earlier source read, retrieval freshness, source reacquisition, temporal
supersession and human validity assessment still require their separate gates.
