# Alden 0.3.71 — 수동 품질 확인

지식 그래프의 기존 정보 창에서 **품질 확인**을 누르면 선택한 프로젝트의 허용된 현재 수집 기록을 검사한다. 상단 한 줄과 그래프 배치를 유지하며 자동 폴링을 추가하지 않는다. 기억·대화 영역은 이 검사 대상이 아니며 검색·출처·대상·유형·관계·기간의 화면 필터도 적용하지 않는다. 화면에 그린 노드 수와 전체 검사 범위를 구분한다.

표기 정규화 차이와 그 밖의 무결성 지적, 동일 원문 해시 참조·같은 수집 맥락/다른 맥락의 검색 문자열 일치·벡터 차원 혼합 후보를 보여준다. 지적이 없거나 문자열이 같다는 사실로 의미상의 진실·동일 인물·중복 자료·이상치 여부를 판정하지 않는다. 원문 바이트를 다시 읽지 않으며 기존 NFC/줄바꿈 규칙과 본문 공백 보존을 확인한다. 날짜·단위·별칭·한국어 표현의 의미 정규화와 독립 원문 gold는 미완료다.

`collection-quality`는 설정/등록부 변경 dispatch 전에 실행하는 읽기 전용 경로다. 요청은 `{ "scope": "all" }` 또는 `{ "scope": "project", "project": "exact-id" }`다. 실제 이름이 `all`인 프로젝트와 전체 범위를 구분한다. 기존 v3 저장소가 없으면 생성하지 않는다. 최대16프로젝트·10만 행·512MiB·10초이며, 원문 블롭 검증과 ID 표본은 꺼 둔다. 취소 확인은50ms 간격이며 시작/종료에도 중단 상태를 확인한다.

범위·대상 권한·DB 파일 교체와 전체 프로젝트 목록을 조회 전후 대사한다. 동시 프로젝트 등록이 전체 범위를 일부 결과로 바꾸던 회귀는 수정 전 실패와 수정 후 통과를 보존했다. 취소·예산 초과·잘못된 요청/보고서는 미확인으로 반환하며 부분 결과를 완료로 보여주지 않는다. 숨김·정보 창 닫기·프로젝트 전환·dispose는 늦은 응답을 차단한다.

관측에는 집계·범위·확인 시각과 제한된 지적만 포함한다. 본문·원문·문서/대상 ID 표본·URL·인증 값은 제품 결과에 넣지 않는다. Collection과 retrieval은 별도 읽기 스냅샷이며 버전/해시 연결을 검사한다. 두 DB의 원자적 동시 스냅샷을 주장하지 않는다. 검사 자체는 수집·병합·삭제·인덱스 수정·모델 로딩이나 새로운 지식 활동을 만들지 않는다.

실제 source 메뉴 CLI의5프로젝트·26,625멤버십·26,623문서·48,355관계에서 형식/연결 지적0, 같은 맥락의 문자열 후보663묶음, 원문 해시 참조 후보0과 차원 혼합 후보0을 확인했다. 최초 관측6.25초/137,117,262처리바이트는 한 요청의 처리량이며 고유 원문 크기·메모리·성능 개선의 측정이 아니다.

UI전체645·추가 범위 수정 후43집중검사/타입, native127·strictClippy와 pinnedPython59를 통과했다. 요청한 GPT-6 Web/xhigh 두 작업자의 실제 턴 모델을 확인하고 병렬 UI/독립 계약 검사를 통합했다. 설치 런타임 소스는 `b4dfd9d20cdab78622795d821aa7bc975ca4852f`다. 후보·설치의 실제 읽기 전용 native14상태/28PNG와 기본/작은 창의 품질 버튼을 확인했고 영향4PNG를 직접 검토했다. 작은 창의 긴 정보는 팝오버 내부 스크롤이며 물리 스크롤·Retina 검증과 구분한다.

설치63파일/모드/strict deep ad-hoc 서명과 후보가 일치한다. 설정3·대상7·정책2·모델 listener·음성 이력과 독립0.3.70 복구본이 유지됐다. 설치 CLI 전체 조회는5프로젝트/26,625멤버십/48,355관계·같은 맥락 문자열663후보, 취업 단일 조회는12,561멤버십/22,388관계·문자열 후보0, 미등록 범위는 미확인 오류였다. 전체 설치 조회2.93초는 최초6.25초와 조건·데이터가 달라 성능 개선으로 비교하지 않는다.

검수 중 기존 스케줄러의 두 유튜브 갱신이 완료됐다. 버전·검색 텍스트·벡터에 각2행이 추가됐고 현재 포인터가 바뀌었다. 과거64,330버전/검색 텍스트·63,410벡터의 바이트 해시를 확인했으며 두 포인터만 되돌려 계산한 문서/멤버십 해시가 이전 상태와 일치했다. 실제 저장소를 되돌리지 않았다. 새 버전·대상·완료된 예약 attempt와 collection/capture run을 대사했으며 기존 갱신을 중단하지 않았다. 저장소 전체가 검수 중 정지해 있었다고 주장하지 않는다.
