# Alden 0.3.91 — 보이는 그래프의 복원과 준비 확인

보이는 지식 그래프가 늦은 포커스 해제 이벤트로 중단되는 경로를 수정하고, 복원 준비 확인에서 전체 점 쌍 계산을 제거했습니다. 검은 배경·작은 점·절제된 군집색·가는 실제 관계선·한 줄 상단과 기존 좌표/핀/권한을 유지합니다. 첨부 이미지의 외부 제품 벤치마크 수치를 Alden 성능으로 사용하지 않습니다.

설치 앱은 0.3.91입니다. 런타임 소스는 `490547c66283c4dc793c249fde46547a63728aac`이며, 추가 비상정지 회귀는 `948c2b39b83264cb7dc1656f4cd37f5337c4507e`에 있습니다. 독립 0.3.90 복구본, 설치 68개 파일과 모드·strict/deep ad-hoc 서명, 설정·7개 수집 대상·정책·모델 리스너 및 선택한 collection/retrieval/history 표의 보존을 대사했습니다.

## 구현과 회귀

- `auditViewport()`는 점·라벨·투영 쌍을 순회하지 않고 화면 사각형을 읽습니다. 종료/상세 보기의 unavailable 상태와 기존 좌표계도 유지합니다. 독립 검토로 발견한 두 상태 회귀는 수정 전 실패, 수정 후 통과했습니다.
- 준비 조건과 기존 96초 전체 예산·16KiB 응답 상한을 유지합니다. 실패 시 자료 로딩, 카메라/물리 이동, RAF, 요청 상태, 문서 가시성과 마지막 중단 상태를 제한된 진단으로 남깁니다. 식별자나 본문을 추가하지 않습니다.
- 설정의 그래프 데이터 화면에만 `pauseOnBlur: false`를 적용합니다. 실제 `bootSettings()` 통합 테스트에서 native visible 뒤 late blur가 요청을 중단하는 회귀를 재현했습니다. native 숨김, 비활성 페이지와 종료는 계속 중단합니다. 기본 lifecycle 정책과 사이드바 orb는 변경하지 않습니다.
- 실제 `setEmergency()`·음성 envelope·렌더 함수·RAF를 사용하는 제한된 fixture에서 비상정지 latch가 세 번의 표시 요청 뒤에도 유지되고 각 요청의 한 프레임 후 유휴로 돌아가는 것을 확인했습니다. 물리 단축키나 전체 추론 취소 검증을 대신하지 않습니다.

Web GPT-6/xhigh 검토 두 건은 제공된 코드 텍스트에 한정했습니다. 각 세션의 실제 모델/추론 설정과 종료를 확인했습니다. 저장소 전체·물리 사용·원문 의미 gold를 검토한 결과로 쓰지 않습니다.
