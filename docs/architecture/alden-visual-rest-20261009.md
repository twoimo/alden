# Alden0.3.54: 경계에 정착한 그래프의 시각적 정지

타원체 경계 투영은 내부 적분 속도를 조금 남길 수 있다. 실제 좌표가 정지해도 기존 속도 기준을 약간 넘으면 PlasticityLayout.moving이 계속 true이고, Hologram은 이를 높은 렌더 갱신 빈도의 원인으로 사용했다. 원문·관계·학습이나 의미 유사도의 문제와 구분한다.

설치0.3.53의 읽기 전용 dispatcher에서 현재 허용된5프로젝트의 표시 노드1984개·관계3789개를 취득했다(전체26623/48355, 기억 overlay 제외). 실제 renderer의 물리 용량은120노드/512시냅스이며 이 자료에서는9시냅스였다. 나머지 표시 노드의 source/space seeded anchor를 전체 의미·힘/방향 군집으로 해석하지 않는다. 60회 anchor 계산은 p95 2.141ms였고 이는 Node CPU 기준선이며 실제 GPU/FPS나 개선율이 아니다.

고정1/60초 수치 실행에서100초 뒤에도 moving=true, 최대 내부속도0.00171554/힘0.02371549였다. 그러나20초부터100초까지 실제 좌표의 최대변화는3.97e-13이었다. 실제 사용자 scene에서 분리한 익명 수치 회귀 fixture는 원문·표시명·원본ID를 포함하지 않으며 의미 평가 gold가 아니다.

투영 뒤 실제 좌표 이동을 display units/second로 측정한다. 기존 저속/저힘 조건을 유지하고, 내부속도<0.003·힘<0.025인 상태에서 실제 이동속도<1e-6이12단계 이어져도 시각적 정지로 판정한다. 위치를 새 anchor로 순간 이동시키거나 모든 힘이0이라고 주장하지 않는다. 새로운 target signature는 다시 움직이게 하고 이전 위치를 유지한다. 변화 없는 signature와 쉬는 advance는 좌표를 수정하지 않는다.

동일 자료의 수정 후 수치 실행은530프레임/8.825 simulated seconds에 moving=false였다. 최종 위치는 기존100초 위치에서2e-6이내였으며, 변경 후 target 재개도 회귀로 확인했다. 호출당 CPU 백분위는 서로 다른 초기/정착 구간이 섞여 있어 단순 속도 개선율을 보고하지 않는다. 100초 이전/이후 고정 수치 재현, 실제 설치 owned renderer 관측, 실제 primary/FPS/GPU/배터리를 각각 구분한다.

관찰 전용 native audit는 기본/작은 창의 실제 표시 scene에서 physics 상태를 최대15초 기다리고2초 뒤를 다시 기록한다. restObserved=false여도 물리 정지가 검증됐다고 바꾸지 않는다. primary·실제 입력·GPU·배터리와 의미 군집 완료를 이 관찰로 대신하지 않는다. 감사 제어 쓰기와 추론은 계속 허용하지 않는다.

검증: UI414개, 관련 물리22개, Rust109개와 strictClippy 통과. 초기 익명회귀2개 실패 중 하나는 실제 moving 버그, 다른 하나는 경계 재투영의 마지막 이진자리까지 동일하다는 과도한 새 assertion이었다. 위치 보존은1e-12 허용 오차로 수정하고 로그를 보존했다. source/CI/build/install/native/signature는 각각 별도 전달 영수증을 사용한다.

GPT6Web 최고추론 병렬 구현/설계는 모델을 대체하지 않고 재요청했지만 OpenAI 도구 승인 검토의 보안 상태 판단 불가로 막혔다. 의미 affinity 코드·힘/방향 설계 산출물은 없으며, 의미 중복/이상치/대규모 semantic grouping은 미완료다. 이 수정은 실제 정지에도 계속 움직임으로 판정하던 시각화 수명주기 문제를 해결하는 독립 작업이다.
