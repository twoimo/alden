# Alden 통합 지식 그래프

기억·대화와 허용한 프로젝트 수집 자료를 하나의 기본 화면에 표시한다. 프로젝트와 출처 선택은 이 화면의 필터다. 각 원본 저장소의 접근 규칙과 버전은 유지하며 서로 다른 사람·문서의 이름이나 ID를 임의로 합치지 않는다.

## 저장과 표시

화면의 그래프는 허용된 collection projection과 memory reader의 합집합이다. 기억의 표시 ID는 `memory:<canonical ID>`이고 상세 조회는 원래 ID로 보낸다. 출처 사이의 연결은 생성하지 않는다. 프로젝트·대상·플랫폼 필터는 수집 자료의 원격 허용 범위로 전달하며 관련 없는 기억을 제외한다. 기억 검색·유형·관계·시간 필터는 이미 허용된 기억 읽기 결과에 적용한다. 부분 실패는 화면에 표시한다. 이것은 논리적 통합이며 원본 데이터베이스를 강제로 합치는 작업이 아니다.

## 전체 화면과 상세 화면

첨부 이미지의 검은 공간, 작은 색 점, 가는 연결선과 절제된 이름 표시를 지식 그래프 화면에 적용했다. 입자는 실제 저장 노드이고 선은 실제 관계다. 샘플 이미지의 이름·작업 상태·숫자는 가져오지 않았다. 전체 화면은 수집 노드1984개와 기억64개, 합계2048개 및 연결4096개까지 표시한다. 수집 자료만 보면1984개다. 더 보기와 목록은 다른 자료에 접근하는 경로다. 전체 자료 수는 현재 표시 수와 구분한다. 빈 제목은 저장된 원본 ID로 표시한다.

수집 전체 화면의 선택 순서는 대상마다 degree와 안정적인 ID로 정렬한 순번을 교차한다. 출처 규모가 다른 경우에도 작은 대상이 처음부터 사라지지 않게 한다. 선택 후 실제 주변 확장은 최대24개·3홉이고 기존 원문·버전·해시 확인을 유지한다. 선택 색은 분홍, 직접 연결은 청록과 금색으로 강조한다. 배경 군집 색은 출처 표시이며 신뢰도나 사실 여부를 뜻하지 않는다.

## 계산과 수명주기

큰 전체 화면의 위치는 안정적인 원본 ID와 출처 ID로 결정한다. 위치 계산은 O(V), 연결 업로드는 O(E)이며 각각 위 예산으로 제한한다. 출처별 군집은 탐색용 배치이며 의미 관계가 아니다. 실제 관계에 따른 물리 갱신은 기존120노드·512연결 solver 예산으로 제한한다. 노드와 연결은 재사용하는 GPU buffer로 그린다. 숨김 시 기존 단일 렌더 루프·읽기 타이머 중단을 유지한다. 오버레이 크기 변화만으로 카메라를 초기화하지 않으며 실제 창 크기 변화와 탐색 이동만 새 시점을 설정한다.

## 검증 범위

집중 Python51개, UI392개, Rust108개, Clippy와 프론트 빌드가 통과했다. 설치0.3.36에서 시작한 이전 화면의 native capture는 기본·선택 화면을 만들었으나 back의 상세 조회가5초 안에 끝나지 않아 전체 감사는 실패했다. 첫0.3.37 후보는 검은 화면과 실제 군집을 그렸으나 확대→이전 복원 검사가 실패했다. 실패 영수증을 보존하고 수정 중이며 렌더링·설치 완료로 보고하지 않는다. 실제 collection 저장 자료26622개·관계48355개에 대한120/720노드 읽기 영수증은 비공개 작업 출력에 보존했다. 서로 다른 표시 예산과 콜드/웜 조건의 n=1 시간으로 성능 향상을 주장하지 않는다.

실행 소스 CI, 최종 native QA, 설치 파일·설정·모델 프로세스 되읽기 및 서명 릴리즈·프로덕션 상태는 이후 영수증으로 갱신한다. 전체 Alden 목표는 진행 중이다.

2026-10-08 후보 최종 native WKWebView 검증이 통과했다. 실제 수집1984개와 기억64개, 합계2048개 및 연결3795개를 표시했다. 기본1200×760, 최소640×648의 전체·선택 원문과18개 화면을 확인했으며 페이지·확장·이전·숨김·복원 검사를 통과했다. 감사창은 물리적 마우스 입력을 통과시켜 기존 앱의 사용을 방해하지 않는다. 이 감사는 설치된 primary/tray/물리 마우스·키보드·화면 잠금 검증과 구분한다. 최종 서명 배포는 미완료다.
