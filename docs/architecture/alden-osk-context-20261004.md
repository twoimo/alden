# Alden OSK 조직과 의미 있는 모션 — 0.3.17

기존 구현은 실제 OSK SDK를 사용하면서도 인물·대화방·주제에 따른 고정 배치와 합성 `contains` 연결을 추가했다. 이 구조를 출처에 따른 실제 Scope 배치와 허브 Link, 원문에서 확인한 관계로 바로잡는다. 이 문서는 이전 `alden-osk-knowledge` 보고서 이후의 변경을 다룬다.

OSK는 `lpaiu-cs/osk-system` v4.1.2, commit `9bbf08febc5a1fb2af068006735ed79cbdb71178`을 고정한다. Constitution §6의 Person은 사용자 자신을 다루는 공간이며, 다른 대화 상대를 일괄 배치하는 분류가 아니다. Bylaws §3 및 Mechanism §9-4에 따라 실제 경로와 본문 Link로 배치·항해·복구를 확인한다. 화면의 가까운 거리는 OSK 군집 판정이나 뇌 학습의 증거가 아니다.

단일 방에 근거가 있는 84개 기억은 그 출처 맥락에 두고, 여러 방에 걸치거나 방을 특정할 수 없는 31개는 공통 출처 입구에 둔다. 화면에 표시되지 않는 방의 근거도 소속 판단에 포함한다. 과거 노트와 원자료는 보존한다. 실제 SDK를 통한 배치 전후 비교에서 활성 기억 115개의 ID·출처 내용·Raw 좌표, 기존 관계 398개와 불변 Raw 텍스트 4,897개(2,226,095,032 bytes)가 보존됐다. 유형별 합성 연결 118개는 0개, SDK의 허브 도달 불가 기록 98개는 0개가 됐다. 이는 검증된 구간의 결과이며 의미 판단 전체의 완벽성을 인증하지 않는다.

독립 검토는 네이티브 `gpt-6-astra/xhigh` 세 에이전트와 `claude-opus-5-5-high/high` AGY 코드 리뷰로 수행했다. 네이티브 세션의 provider/model/effort, AGY의 현재 모델 목록·실행 인자·백엔드 선택 label과 완료 응답을 확인했다. 리뷰가 찾은 이동 중단 복구, 인간의 개명 누락, 허브 변경 감지, 만료 관계의 역방향 재등장, 항해와 의미 관계의 강도 혼동을 재현·수정했다. 다중 리뷰는 편향 제거를 보증하지 않는다.

방 이름은 전체 게시 Corpus, 등록·과거 이름, 제한된 원문 참여자·주제 근거를 조회한다. 현재 원본 관측은 같은 DB reader/트랜잭션의 account fingerprint와 숫자 room ID에 결속한다. 실제 제목, 원본의 기본 표시 이름, 지역 별칭, 보관 기록 식별 이름은 서로 다른 `label_source`로 유지한다. 빈 이름이나 오래된·다른 계정 관측이 알려진 제목을 지우지 못하며 원본 카카오톡 방 이름은 수정하지 않는다. `제목 미확인`을 단순 치환해 확인 완료로 처리하지 않는다.

움직임은 실제 관계·근거 변경, 새로 표시되는 연결, 유효성 시작/만료, 사용자 탐색과 실제 음성 RMS에 연결한다. 반복 흔들림, 뇌 배경의 반복 팽창, 임의 흐름 shader와 전역 작업량에 따른 기억 좌표 확대는 제거했다. 사용자·런타임 작업 상태는 Alden의 별도 상태 orb가 담당한다. 변하지 않은 수집 시각만으로 전체 그래프를 다시 만들지 않으며, 연결되지 않은 새 기억이 기존 연결 성분의 배치를 흔들지 않는다.

모션의 단위는 표시 공간이며 생물학적 시냅스 단위가 아니다. `w`는 보존된 관계 가중치, `s=w/(1+w)`는 표시 강도다. 항해 가중치는 `0.08`, 의미 관계는 자체 근거 가중치를 사용하며 같은 쌍에서는 의미 관계를 우선한다. 배치·물리·리본이 같은 선택을 사용한다. 휴지 길이는 `r(s)=0.3+0.45(1-s)`, 감쇠는 `exp(-11·Δt)`, 연결의 펼침·퇴축은 `g←g+(1-exp(-Δt/0.16))(목표-g)`다. 힘 24, 속도 1.4, 화면 기억 24개·다리 144개 상한을 유지한다. 관계가 바뀌면 영향받는 연결 성분의 배치를 계산하고 정착 후 반복 프레임을 중단한다.

저장된 note·hub의 경로와 inode·크기·mtime·ctime을 제한된 메타데이터 probe로 확인한다. 본문·Raw를 매번 읽거나 SDK를 재색인하지 않는다. 최대 8,192항목·32단계·100ms이며 지원 밖·불완전 판독은 기존 15초 전체 읽기로 돌아간다. 가까운 `validFrom`/`validTo` 경계에는 한 번만 실행되는 타이머를 둔다. 1초 probe는 이미 저장된 변경의 감지 주기이며, 원본 수집 지연이나 화면 반영 지연 전체가 1초라는 뜻은 아니다.

기록된 초기 순수 배치 benchmark는 실제 저장 그래프의 24개 화면 기억, 30회 예열·200회 측정에서 p95 0.847 ms였다. 브라우저 개발 예시에서는 유휴 1초 동안 프레임 증가가 0이었다. 최종 코드에서는 실제 24개 기억의 순수 배치 계산 p95 1.078 ms를 기록했다. 최신 Corpus 재파생과 설치본에서 115개 ID, 관계 397개를 보존했으며 기존 Raw 텍스트 5,041개(2,226,444,121 bytes)의 SHA-256이 유지됐다. 설치본 41개 파일은 빌드와 일치하고 strict/deep ad-hoc 서명이 유효하다. 전용 네이티브 창의 14개 기본·최소 크기 페이지에서 오류·가로 넘침은 0개, 이질적인 첫 프레임 관측 p95는 16 ms였다. [검증 JSON](alden-osk-context-20261004/verification.json)에 서로 다른 범위를 구분해 기록한다. 이 값은 GPU·배터리·음성 응답 개선률이나 세계 최고 성능을 증명하지 않는다.

[구조 그림](alden-osk-context-20261004.html)은 9개 showcase 검사와 네 크기의 브라우저 검사를 통과했다. 1440×900 light 캡처는 별도로 이미지 검토했다. 고정 UI controls는 Archify의 지원 locale에 따라 영어이며 한국어 본문을 사용한다.

실제 기본 창·물리 음성·OS 잠금, 별도 Alden-dot 호출, Flash iQ 메모리 admission, Developer ID·공증은 전체 목표의 독립 검증 항목으로 남는다. 전용 읽기 검증 창과 개발 예시는 그 검증을 대신하지 않는다.
