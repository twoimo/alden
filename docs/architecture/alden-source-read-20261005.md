# 원문 역할과 정본 읽기

OSK의 실제 다음 조직 검토 구간을 읽던 중 두 과거 방 관측에서 사용자 ID가 있는 입장/퇴장 feed 알림이 `peer_history`로 포착된 것을 확인했습니다. 현재 조회는 이런 형식의 알림을 `system_history`로 구분하며, 이후 전체/관련/증분 수집도 같은 판정 함수를 사용합니다. 판정은 DB message_type 0과 JSON의 정수 feedType 형식에 결속됩니다. 일반 텍스트·type 1의 JSON·boolean feedType을 같은 알림으로 간주하지 않습니다. 자기 발신은 사람/자동 답변을 확정하지 않은 기존 구분을 유지합니다.

원본 파일은 다시 쓰지 않았습니다. 정확한 참조·파일 SHA·캡처 역할·유효 역할·형식 근거를 가진 별도 비공개 role review로 16건의 정정 근거를 보존했습니다. 이는 검토한 두 노트의 8건씩에 한정된 기록이며, 전체 Raw 역할 정정 완료가 아닙니다. 오래된 Raw를 직접 읽을 때 원래 포착 역할과 현재 해석을 구분해야 합니다.

같은 검토에서 실제 출처의 방 ID가 `kakao:<account>:room:<number>`인 반면 질의는 숫자인 것을 확인했습니다. 0.3.25의 비교로는 실제 활성 방 관측 40개가 모두 범위에서 제외됐습니다. 0.3.26은 검증된 계정 접두부를 유지하면서 방/발화자 ID를 숫자로 정규화합니다. 계정이 불일치하면 범위에 넣지 않으며 이름으로 병합하지 않습니다. 실제 40개 판정이 0→40으로 바뀐 것을 확인했고, 한 활성 노트는 실제 숫자 방 조회에서 반환됐습니다. 판정 검사와 한 실제 조회를 모든 방의 의미 정확성으로 확대하지 않습니다.

## 같은 바이트를 한 번 읽기

이전 준비 경로는 SDK Index가 노트를 파싱한 뒤 반환 문서의 해시를 위해 같은 파일을 다시 파싱했습니다. 대상 참조도 추가 파싱했습니다. 현재 경로는 해당 요청에서 실제 읽은 바이트를 SDK contract로 한 번 파싱해 그 요청의 Index에 넣고, 그 바이트로 해시를 만듭니다. SDK의 전체 중복 ID/이름·파손·불완전 판정은 유지합니다. 다음 요청은 새 Index와 바이트를 읽으며, 선택 노트의 최종 SHA 재확인은 남습니다.

노트 ID·경로·본문·참조·출처·시점·전체 snapshot 값의 전후 객체가 모두 같음을 대조했습니다. 파싱 중 파일이 바뀌면 응답을 거부하고, 다음 읽기는 변경된 본문을 반환하는 회귀 검사를 포함했습니다. 오래된 캐시 본문에 새 디스크 해시를 붙이는 방식은 사용하지 않습니다.

| 같은 104개 노트 준비 | 이전 | 이후 | 감소율 |
|---|---:|---:|---:|
| wall 중앙값 | 182.371ms | 146.382ms | 19.73% |
| nearest-rank p95 | 213.369ms | 179.103ms | 16.06% |
| process CPU 중앙값 | 179.988ms | 144.226ms | 19.87% |

각 경로 20회, 같은 warmed process에서 순서를 교차했습니다. 회귀 검사 프로세스가 종료된 뒤 측정했고 기존 운영 worker는 유지했습니다. 다른 호스트 부하는 통제하지 않았습니다. 감소율은 `(이전−이후)/이전×100`입니다. 앞선 회귀 검사와 동시 실행된 프로파일/시험 측정은 최종 표에 사용하지 않았습니다. 이 표는 정본 준비만 포함하며 embedding·LLM·UI·앱 전체 CPU/RAM/GPU/전력·음성 지연을 입증하지 않습니다.

## 조직 검토와 남은 범위

선택된 원문 탐색 입구의 전체 구간과 실제 wiring은 검토했고, missing/bypass 연결이나 pending move는 없었습니다. 이 입구는 실제 노트의 탐색 지도이지 주제 분류나 imported 관측의 의미 승인 근거가 아닙니다. SDK의 현행 snapshot에 묶인 부분 영수증으로 한 구간만 checked 처리해 남은 범위가 104→103단위가 됐습니다.

두 과거 방 노트는 inactive이며 현재 게시된 corpus에는 해당 방 행이 없었습니다. 참조한 metadata의 제목도 비어 있었고 메시지 근거 8건씩은 시스템 알림이었습니다. 과거 본문의 메시지 수/기간을 현재 대화나 의미 지식으로 확정하지 않았습니다. 수리·배치·제목 근거 확인이 끝나지 않아 이 두 구간은 checked에 넣지 않았습니다. 개인 원문·이름·주소는 이 문서와 배포물에 포함하지 않습니다.

141개 영향 검사와 실제 SDK·source 포착·역할·범위·취소 검사가 통과했습니다. 원본 Raw, 수동 지식, 운영 worker·설정·전송 큐를 보존하며 전체 의미 검토, 넓은 독립 검색 평가, 물리 음성/primary/tray/Retina/lock/shortcut, Flash-Next, Dot, 전체 앱 비교, Developer ID·공증·production은 계속 남아 있습니다.
