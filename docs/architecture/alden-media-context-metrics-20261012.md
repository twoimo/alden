# Alden 0.3.70 — 사진 비교와 요청별 관측 기록

새 사진을 첨부하면 이전 사진이 모델 입력에서 빠지던 경로를 수정했다. 현재 사진을 우선하고, 같은 대화의 최신 완료된 턴에서 고유한 사진을 가져온다. 합계4장/20MiB 상한과 SHA/MIME 중복 제거를 적용한다. 한도·접근 실패로 빠진 사진을 명시하며 철회되거나 다른 대화의 사진을 사용하지 않는다.

추론 전과 답변 저장 전에 이전 사진의 요청·턴·대화·완료 상태·바이트 근거를 재검증한다. 실제 전송 SHA/MIME/바이트 목록도 선택한 사진 목록과 일치해야 한다. 사진이 변하거나 철회되면 해당 답변을 저장하지 않는다. 원래 사진·대화 기록은 보존한다.

`alden_chat_generations`는 요청별 제한된 JSON 관측을 저장한다. 답변과 관측은 같은 트랜잭션에 저장하며 완료 요청을 재조회하면 원래 관측을 반환한다. 취소·실패는 관측만 보존하고 답변을 생성하지 않는다. 이전 관측이 없는 기록도 읽을 수 있다.

선택 모델과 실제 응답 모델은 별개다. 이번 실제 요청의 선택 ID는 `google-antigravity/gemini-3.8-flash`/high이며, 응답이 보고한 ID는 `gemini-3.8-flash`다. 사용량은 실제 보고된 값만, 지연은 측정된 범위와 함께 저장한다. 비스트림 응답의 전체 완료 시간을 첫 토큰 시간으로 표시하지 않는다. 프롬프트·원시 사진·URL·인증값은 관측 기록에 넣지 않는다.

대화 답변 아래의 접힌 상세에서 응답 모델·처리 시간·관측 토큰 수와 현재/이전 사진 수를 확인할 수 있다. 미확인 응답 모델은 요청 모델로 구분한다. 기존 대화와 사용자 메시지의 모양·내용을 보존한다.

로컬 검증은 UI616/native126·타입·strictClippy, 추가 DOM22와 제품 pinnedPython73을 통과했다. 실제 전송 사진의 불일치·취소 관측의 영속성·완료ID 불변성·철회·입력 한도·캐시 실패·다른 대화를 포함한다. 모듈형 CI 실행에서 새 테스트 import 오류를 수정하고4개 영향 모듈을 CI에 등록했다. 사진 입력 검수에는 실제 빨간 배경/흰 원과 파란 배경/노란 사각형을 사용했다. 이전 답변은 첫 사진의 배경만 언급하므로 마지막 도형 비교는 이전 사진의 실제 입력을 요구한다.

최초 후보는 손상 사진12건을 추론 전에 거절했고, 실제3턴에서 `빨간색`, `42`, `흰색 원, 노란색 사각형`을 답했다. 같은CID의 요청3/관측3/메시지6/세션1이며, 마지막 요청의 실제 사진2장과 근거가 일치했다. 마지막 PNG에 이전 화면이 남은 관측은 보존하고, 후속 검수는 두 paint 프레임과 최신 답변의 화면 내 범위를 확인한다.
