# Alden 0.3.61 — 밀집 배치와 라벨, 품질 감사

2048개 표시 노드의 충돌 계산을 앞쪽 ID가 먼저 소진하던 경우, 뒤쪽 노드가 같은 좌표에 남고 이후 인력 계산으로 다시 뭉칠 수 있었다. 매 계산 단계와 움직이는 노드에 예산을 나누고, 혼잡한 공간 셀의 대표를 순환한다. 같은 셀의 후보와 반복 좌표를 재사용해 비용을 제한한다. 가져온 정확한 중첩 좌표에는 ID별 결정적인 방향과 반 간격을 적용한다. 고정 위치와 바뀌지 않은 성분, 노드 ID·관계·권한·버전을 보존한다. 아직 전체 충돌을 푼 것은 아니며 표본 절단을 진단에 남긴다.

상단 그래프 라벨은 선택한 노드, hover, 대표 반경 순으로 배치한다. 15개 이내의 주변 화면 위치에서 기존 라벨과 패널 제외 영역을 피한다. 원래 노드·관계와 키보드 접근 경로를 유지하며, DOM 폭은 그래프·hover 변경 시에만 다시 측정한다. 자리가 없는 라벨은 숨겨질 수 있다.
