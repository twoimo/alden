# Alden 0.3.53 원본 자동 확인

기존 macOS 수집 일정은 로그인 세션에서 1분마다 예정 대상을 확인한다. 대상별 원본 자동 확인을 켜면 해당 영상의 기존 수집 주기에 Aside native YouTube 메타데이터·트랙·한국어 타임스탬프 자막을 새로 읽는다. 이 옵션은 기존 단일 영상 표본에만 적용하며 채널 전체·계정 목록·댓글·영상 픽셀을 취득하지 않는다. 다른 출처의 스냅샷 수집은 계속 독립적으로 동작한다.

`collection-scheduler-control`의 명시적 `acquisition` 작업은 target_id, enabled, expected_revision을 받는다. 정책은원문 저장소·대상 설정과 분리된 scheduler DB에 기록한다. 정책 저장 전 비공개 이전 값 백업과 현재 revision을 대조한다. 초기값은 꺼짐이며 등록된 `youtube-video` 표본·현재 권한·활성 상태·설치된 Aside CLI를 확인한다. 기존 주기·프로젝트·권한·체크포인트·모델·전송 큐와 비상 중단 상태를 바꾸지 않는다.

현재 호스트는 이미 확인한 local/u0다. 기존 로그인과 프로필을 사용하며 계정 검색·전환, agent/LLM 요청, 브라우저 탭 생성이나 유료 용량을 추가하지 않는다. 지원되는 native 세 메서드로 읽고 원문 ID/URL·관측 시각·자막 종류의 불확실성·선언된 상위 문맥을 보존한다. 표시명은 안정적인 작성자 ID가 아니다. CLI 반환 바이트의 크기·형식과 실패 단계를 검사한다. 별도 임의 셸·원격 호스트나 전역 MCP 연결 권한은 없다.

취득 성공은 입력 CAS·private 이전 바이트 보관·atomic publication으로 이어진다. 정책 변경·중지·음성·비상 중단·시간 예산이 먼저 도착하면 게시하지 않는다. 소유한 CLI 클라이언트만 종료하며 호스트 쪽 읽기가 실제 취소됐다고 주장하지 않는다. 실패한 취득은 수집 완료로 대신하지 않는다. 재시도는 기존 대상별 backoff를 사용한다.

새 입력의 수신 영수증을 저장·색인 전에 scheduler attempt에 영속 기록한다. 이후 단계가 실패하거나 프로세스가 중단되면 현재 원본 해시와 정책 revision을 확인해 이미 받은 자료로 복구한다. 기존 자료가 바뀌었거나 정책이 변경됐다면 이전 영수증을 새 입력에 적용하지 않는다. 입력 수신·자료 저장·원문 보관·검색 가능 상태는 각각 별도 근거로 검증한다.

사용 화면은 기억 정리→정기 수집→대상의 주기 펼침→원본 자동 확인 켜기/끄기다. 지원하지 않는 대상에는 이 제어가 나오지 않는다. 최근 처리와 원본 확인/접근 실패를 구분한다. 두 영상 표본의 실제 background 실행·원문/검색/화면 검증과 전체 채널·여러 독립 호스트·장시간 반복 실행은 별도 완료 조건이다.
