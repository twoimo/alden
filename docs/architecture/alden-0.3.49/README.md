최종 deliver는 각각 9/9 showcase 검사와 오류·경고 0개를 통과했습니다. 정확한 HTML 바이트를 Chrome에서 검사했고 1440×900·1600×1000·1920×1080·2048×1320의 넘침·가독성 검사가 모두 통과했습니다. 양 끝 크기의 밝은/어두운 PNG 총 36개를 이미지로 직접 검토했습니다. 최초 시스템·계보 도식의 세로 넘침은 보존하고 여백을 조정한 뒤 재검증했습니다.

[manifest](manifest.json)는 도식 종류, 원본 JSON/HTML SHA-256, 실제 코드 SHA, 전달/브라우저 영수증과 별도 시각 검토를 연결합니다. `*-delivery.json`은 결정적 산출물 검사, `*-browser.json`은 브라우저 검사입니다. 브라우저 영수증의 `visualReview: pending`은 그대로 두고 이미지 검토 판정은 manifest에 별도로 기록했습니다.

도식은 구현 경로와 남은 검증 경계를 설명합니다. 제품의 물리 음성·전체 호스트 연결·전체 병합/독립 평가·Developer ID/공증/프로덕션 완료를 입증하지 않습니다. 설치 앱·모델·큐·사용자 데이터는 이번 문서 작업의 변경 대상이 아닙니다.
