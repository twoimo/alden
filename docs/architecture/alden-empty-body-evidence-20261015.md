# 빈 본문과 제목 참조의 근거 경계

설치118의 `source-content-evidence-v5`는 빈 본문과 공백만 있는 본문도 기본 `content_candidate`로 분류했다. 제목으로 만든 정상 E5 벡터가 있으면 본문 근거를 사용하는 의미 배치 경로에 들어갔다. 현재 버전·허용범위·원문/벡터를 검증한 결정적 표본24개 중15개가 빈 본문이었다. 제목만으로 원래 영상·문서의 본문을 확인했다고 해석할 수 없다.

`source-content-evidence-v6`은 명시적 noncontent 선언과 자료 설명 검사를 유지한 뒤, 정규화된 본문이 빈 경우 `empty_body`로 분류한다. 숫자0·짧은 단어·실제로 보존된 문장은 그대로 콘텐츠 후보일 수 있다. 제목 조회와 원문·문서·구조 관계·기존 저장 벡터는 유지한다. 검색 답변의 근거에는 `title_or_label_reference; original body unavailable`과 ‘제목·이름 참조 · 본문 없음’을 표시한다. 빈 본문은 본문 기반 유사도·본문 일치·동일인 확인의 근거로 승격하지 않는다.

품질 패널은 본문이 없는 참조를 별도로 집계한다. 비본문 총계에는 이 카운터를 포함하고 현재 버전 수와 대사한다. UI의 품질·유사도·동일인 소비자는 v6 계약을 요구하고 이전 정책 payload를 거절한다. 새 정책은 원문·벡터를 다시 쓰거나 임베딩을 재생성하지 않는다. 제목만으로 가능한 약한 주제 연결은 별도 근거 계약과 평가가 필요한 후속 범위다.

## 같은 스냅샷의 대사

단순히 설치118과 새 실제 조회를 비교하면 graph revision이462485→462491로 달랐다. 이를 동일 조건의 개선율로 사용하지 않았다. 대신 같은1,984개 caller refs를 하나의 collection/cache 읽기 트랜잭션 쌍 안에서 검증하고, 설치118 분류 함수와 새 함수를 순서대로 적용했다. 다른 권한·원문·버전·본문·벡터 검사는 같은 제품 로더를 사용했다.

- 기존 분류로1,227개, 새 분류로349개 벡터를 허용했다.
- 차이가 난878개는 모두 빈 본문이었다. 나머지 허용 노드의 proof·벡터·norm은 같았다.
- 기존 source metadata469·URL 참조231·파생 자료 설명56·오래된 graph version1개는 양쪽에서 동일하게 거절했다.
- 파생 DB의 WAL/SHM 읽기 metadata 변동만 허용하는 기존 소유자 계약을 사용했고 금지 SQL 쓰기는0이었다.

별도 실제 소스 API는1,984개 중349벡터와496개 배치 후보를 반환했다. 같은 프로젝트의 허용된44,173쌍 전부를 비교했지만, 이는 의미 정확도나 전체 그래프의 쌍 범위를 뜻하지 않는다. 기존0.65를 모두 넘은 사실 역시 의미 gold가 아니다. [E5 공식 모델 카드](https://huggingface.co/intfloat/multilingual-e5-small/raw/main/README.md)는 높은 절대 코사인 범위가 예상되며 상대 순위가 중요하다고 설명한다. 모델·접두사·코사인 임계값·랭킹 및 자원 예산은 이번 수정에서 바꾸지 않았다.

## 검증과 남은 범위

빈/Unicode 공백 본문·강한 제외 선언 우선순위·짧은 실제 본문·제목 검색 유지·동일한 빈본문 벡터 거절·집계와 이전 계약 거절을 검증했다. 수정 전 새 테스트는12개 subcase에서 실패했다. 관련 Python256·UI886·타입 및 exact-source CI38733624765 네 작업이 통과했다. 정상 build72.603초와 canonical 검사를 통과한 소스 `ab51aa6a6a7f1aef833cc8eb6a2f93dfe60aaeb5`의119를 로컬 설치했다.

최초 실제 품질 조회는 기존10초의 `quality_time_budget`으로 실패했다. 제한을 유지한 계측 진단은9.245초의 action으로 완료했고,26,626회 행 읽기/디코딩의 누적 비용3.022초가 가장 컸다. 이후 동일 코드의 비계측 확인은5.461초, 후보9.254초, 설치6.837초에 완료하고26,625개 현재 버전 중 빈 본문 참조1,932개를 집계했다. 계측·캐시 상태 차이가 있어 이를 성능 개선율로 쓰지 않는다. 첫 실패를 보존하며 반복/냉간/p95의 시간 제한 신뢰성은 별도 미완료다.
