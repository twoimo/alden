# 현재 지식 그래프의 읽기 전용 품질 감사

`scripts/alden_graph_quality.py`는 기존 CollectionStore v3의 권한 있는 현재 멤버십을 감사한다. 현재 프로젝트별 버전을 사용하므로 다른 프로젝트의 더 최신 전역 버전으로 바꾸지 않는다. 거부된 프로젝트, 삭제된 멤버십과 보관본만 남은 버전은 범위에서 제외한다. 문서의 원본 ID와 현재 버전 ID를 유지하며 병합·삭제·수집·색인·모델 로딩을 수행하지 않는다. 개발 CLI이며 설치 앱에 새 진단 화면을 추가하지 않는다.

```sh
python3 -B scripts/alden_graph_quality.py \
  --state-root '/Users/twoimo/Library/Application Support/openkakao/bujamentor' \
  --project career --project sparkuniverse --project jangsin \
  --project youtube-tzuyang --project alden-model-research --verify-sources
```

Mac 제품 검증에서는 기존 고정 Python3.11 런타임을 사용한다. 출력은 집계, 해시와 제한된 ID 표본이다. 본문·메타데이터 내용·엔드포인트나 인증 값은 출력하지 않는다. 대상과 버전이 다른 자료의 동일 정규화 문자열은 검토 후보이며 엔터티 동일성이나 독립 출처의 증거가 아니다. Unicode NFC·공백 정규화와 날짜·단위·한국어 표기·별칭의 의미 정규화를 구분한다.

## 측정 범위와 결과

2026-10-09 실제 등록된 5개 프로젝트·7개 대상의 현재 멤버십 26,625개에서 문서 ID 26,623개를 확인했다. 관계는 48,355개다. 동일 문서가 부모 채널과 영상 표본에 서로 다른 현재 버전으로 남는 두 경우를 문서 중복으로 세지 않는다. 권한 범위 안의 기록 원문 블롭 26,625개와 약 103.9MB를 확인했다. 블롭은 수집기가 보관한 canonical record JSON이며, 원본 전체 export·PDF/미디어 바이트·source-capture manifest 검증을 이 감사로 대신하지 않는다.

검사한 안정 ID, 현재 버전 소유권, NFC·공백 정규화, projection/version 해시, 원문 블롭, 보관 원문과 검색 텍스트의 연결, 관계 끝점·근거 해시, 벡터 형식·유한값·단위 길이의 불일치는 0개였다. 이는 출처 내용의 진실이나 의미 검토 완료가 아니다.

| 항목 | 실제 수량 | 해석 |
|---|---:|---|
| 서로 다른 문서의 동일 원문 바이트 후보 | 0개 묶음 | 원문 전체 바이트 해시 기준 |
| 동일 정규화 검색 내용 후보 | 698개 묶음 | career35, sparkuniverse663; 자동 병합하지 않음 |
| 후보 묶음별 문서 수의 합 | 10,315개 | 의미·독립성 판정 전 후보 수 |
| 저장 body가 빈 현재 버전 | 1,932개 | 보관 원문·label에 검색 내용이 남을 수 있음 |
| 실제 검색 텍스트가 빈 현재 버전 | 460개 | 빈 자료 보존; 벡터 미생성 460개와 일치 |
| 현재 버전 벡터 | 26,165개 | 관측 profile1개, 384차원; 품질·군집 증거는 아님 |

연결 수 분포도 기록한다. Spark는 중앙값2·p957·최대9,436이며, 취업은 중앙값1·p954·최대3,567이다. 출처 허브가 많은 자료를 연결하는 경우를 의미 이상치로 표시하거나 삭제하지 않는다. 연결 방향을 무시한 incident degree 통계이며 물리적 힘이나 에너지의 측정값이 아니다.

초기 후보 5개 묶음의 문서 10개를 별도로 대조했고, 각 묶음 안에서 원문 해시가 서로 달랐다. 이 작은 표본은 전체 698개 묶음의 의미 판정을 대표하지 않는다. 표본·본문 발췌·보관 원문·공유 이름과 실제 엔터티 중복을 구분한 독립 검토가 남아 있다.

## 일관성·예산·회귀

Collection DB는 한 읽기 트랜잭션, retrieval DB는 별도의 읽기 스냅샷이다. 두 DB의 원자적 동시 스냅샷을 주장하지 않는다. 프로젝트별 현재 버전과 raw/base/text 해시를 대조해 캐시를 사용하며, `--verify-sources`에서는 보관 원문 내용도 실제 기록 원문 블롭과 대조한다. 파일은 regular-file·no-follow·크기·변경·바이트 해시를 검사한다. 변경되거나 손상된 블롭은 무결성 지적으로 기록하며 정상 검증 수에 넣지 않는다. 예산 초과는 완료 결과를 발행하지 않는 실패다.

상한은 프로젝트16개, 현재 멤버십+관계10만개, 총 검사 바이트512MiB, 원문1건2MiB, 120초다. 기본 표본은 항목 종류별5개, 동일 내용 후보는 프로젝트마다5개 묶음과 묶음마다5개 ID다. 크기·시간 초과는 실패이며 부분 결과를 전체 성공으로 보고하지 않는다. 실제 실행 시간은 해당 evidence JSON에 남긴 단일 관측값이고 앱 FPS·GPU·배터리·검색 품질 개선 수치가 아니다.

고정 런타임의 새 품질 회귀8개와 기존 snapshot 회귀8개, 합계16개가 통과했다. 거부된 범위 누출, 프로젝트별 현재 버전, 공유 문서의 중복 계산, 손상 원문·정규화 불일치, 보관 원문 오귀속, NaN/없는 벡터 바이트, 빈 근거·삭제된 끝점과 예산 초과를 다룬다. 실제 데이터는 수정하지 않았다.

의미 중복·동명이인·표기/날짜/단위 정규화·독립 gold·가역 병합, 의미와 실제 관계에 기반한 큰 그래프 군집, 같은 힘·방향으로 모임의 검증은 여전히 미완료다. 현재 큰 overview는 출처/공간별 배치이며, 작은 관계 뷰의 spring/repulsion/damping을 의미 학습이나 물리 에너지 군집으로 해석하지 않는다.
