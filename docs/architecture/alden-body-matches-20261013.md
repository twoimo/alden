# 제목 없는 저장 본문과 링크 문자열 검사

기존 품질 검사는 유효 제목과 본문이 모두 있는 기록의 결합 문자열을 비교했다.
제목 없는 글과 링크 기록이 빠졌지만 화면의 “동일 정규화 본문” 표현은 본문 전수 검사로 읽힐 수 있었다.
기존 지표를 “제목·본문 일치 후보”로 정정하고 제목·검색 캐시와 독립적인 현재 저장 본문 검사를 추가했다.

## 검사 범위와 의미

`stored-body-match-v1`은 허용된 프로젝트의 현재 문서 버전을 검사한다.
메타데이터 무결성, 자료 설명·미열람 선언·빈 내용 표지를 확인하고 NFC와 줄바꿈만 정규화한다.
본문 공백·탭·URL 대소문자와 파라미터를 유지한다. 프로젝트, 별도 ID·버전과 출처 맥락을 보존한다.
같은 문서의 중복 소속을 중복 문서로 세지 않는다.

URL만 있는 본문은 링크 문자열 일치로 따로 센다. 링크가 같아도 연결된 문서 내용,
작성자·사람·게시물 전체가 같다고 판단하지 않는다. 일반 본문도 반복 안내·광고일 수 있으므로
검토 후보로 표시하고 자동 병합·삭제·원본 수정을 하지 않는다.
“유효 제목 없는 기록”에는 빈 제목과 명시적인 제목 없음·절단 표지가 포함된다.

## 실제 데이터의 읽기 전용 대사

2026-10-13 후보 검사: 허용된 5개 프로젝트에서 본문 12,157건, 유효 제목 없는 기록
11,949건, URL만 있는 기록 825건을 확인했다. 본문 7묶음·36기록과 링크
28묶음·62기록은 career 범위에서 관찰했다. 자료 설명만 있는 sparkuniverse는
검사 가능한 본문 0건으로 보고했다. 기존 제목·본문 후보 0은 그 한정된 기준의 결과다.

별도 SQL·해시 대사에서 같은 개수와 그룹을 재계산했다. 98기록 모두 보존된 JSON 바이트
SHA와 `localOriginalText`의 NFC·줄바꿈 투영을 확인했다. 원본 경로·웹 글·링크 목적지를
새로 열지 않았다. 이는 저장 투영과 보존된 JSON의 결속이며 원래 게시물의 완전성,
사람의 정답 또는 의미 이상치 판정의 증거가 아니다. 5개 범위의 무결성 발견은 0이었다.

## 계약과 검증

제품 응답에는 지표만 전달하고 본문·URL·문서 ID·샘플·해시는 표시하지 않는다.
정책·검사 근거·검사 수·후보 상태가 누락되거나 개수가 불가능하면 성공/0건 대신 사용 불가로 처리한다.
수동 품질 검사에 연결되며 주기적인 무거운 검사를 추가하지 않는다.

관련 Python 67개, 품질 UI 52개와 타입 검사를 통과했다. 설치·네이티브 화면·CI와 보존 검증은
별도 전달 단계에서 확인하고 근거 폴더에 이어 기록한다. 좌표·힘·원래 관계·모델 설정은 유지한다.
검사 시간은 캐시·프로세스 조건이 통제되지 않은 순차 관찰이므로 속도 개선으로 보고하지 않는다.
첨부 벤치마크의 수치는 Alden 측정값으로 사용하지 않는다.
