# Alden 0.3.86 — 관계 버전 결속

현재 관계의 방향·유형·근거가 보존된 같은 버전과 달라도 품질 확인,
그래프 표시와 병합 미리보기를 통과하던 경로를 수정했다. 이력 누락,
같은 버전의 필드 충돌과 근거 해시 손상을 무결성 오류로 처리한다.
정상 상호 방향 관계, 별도 유형, 개정과 멱등 재실행은 유지한다.

## 계약과 경로

`relation_versions`의 키는 `(relation_id, version)`이다. 현재 관계와
같은 키의 `target_id/source/target/type/evidence`가 모두 일치해야 한다.
`version`은 근거 UTF8의 SHA256과도 일치해야 한다. 허용된 범위의
현재 관계만 검사하며, 다른 프로젝트·거부된 대상·대상 필터 밖의
손상은 해당 조회를 차단하지 않는다.

품질 감사는 이력 누락과 필드 불일치를 구분하고 원본을 고치지 않는다.
검색의 기존 검사, 전체/페이지 그래프와 병합 미리보기/결정의 근거
검사에 같은 결속을 적용했다. 페이지 그래프는 기존 materialized CTE와
키 인덱스를 유지하면서 SQL 내부에서 이력 결속과 근거 해시를 검사한다.
정확한 단일 문서 상세 조회는 관계를 표시하지 않으므로 전체 관계를
재검사하지 않는다. 출력 필드와 기존 페이지·행·전송 예산은 유지한다.

수집은 동일 키의 기존 이력과 다른 필드를 조용히 무시하지 않는다.
충돌을 거절하며 현재 관계와 이력 쓰기는 기존 단일 트랜잭션에서
수행한다. 오류 시 기존 이력을 덮어쓰거나 복구했다고 표시하지 않는다.

## 재현과 실제 자료

첫 회귀6검사에서7실패를 재현했다. 이후 두 테이블의 근거만 같이
바꿔 해시를 보존한 경우와 병합 미리보기의 통과도 각각 재현했다.
9개의 관련 새 회귀는 정상 상호 방향/개정/재실행과 권한·대상 분리도
포함한다. 관련 수집·예약·검색·품질·엔티티·가역 검토223검사와
source-check Rust137검사가 통과했다. CI에 새 회귀 모듈을 포함했다.

실제 현재 허용48,355관계는 이력 누락0/필드 불일치0이었다. 실제
전체·취업·국소·문서 상세4범위에서 각3회 before/after 응답의 모든
필드 SHA가 동일했고, 두 품질 감사의 지적은0이었다. 순차 실행과
캐시·소표본 때문에 시간/RSS 차이를 성능 개선으로 주장하지 않는다.

| 직접 조회 범위 | before 중앙값 | candidate 중앙값 |
|---|---:|---:|
| 전체 개요 | 2.181초 | 2.111초 |
| 취업 개요 | 0.962초 | 0.723초 |
| 국소 이웃 | 0.971초 | 0.841초 |
| 문서 상세 | 0.012초 | 0.010초 |

이는 pinned Python의 직접 SQLite 조회이며 실제 사용자 UI/FPS/GPU/
배터리·시작 지연이나 전체 앱의 자원 측정이 아니다. 앱이 사용하는
4MiB wire 변환과 이전의 표시/물리 개선은 유지한다.

## 검증의 한계

이력은 관계의 스냅샷이다. 원래 `original_id`가 별도 이력 열로 남지
않으므로 관계ID 생성 입력 전체를 다시 인증하지 못한다. 현재/이력을
같이 잘못 바꾸고 해시도 새로 만들면 원본 불일치가 탐지되지 않을 수
있다. 기존 버전의 이력 완전성, 원본의 진실·인물 동일성·모순·철회·
supersession·의미 이상치와 실제 내용 중복은 독립 원문 검증이 필요하다.

새 `chatgpt-web/gpt-6-sol/xhigh` 병렬 검토는 위 계약만 평가했다.
실제 metadata와 종료를 확인했으며 코드/실행 또는 사람의 의미 골드로
사용하지 않았다. 이름·공간 근접성·상호 방향 링크만으로 삭제/병합하지
않는다. 원문·계보·프로젝트·권한·보류와 기존 모델 설정을 유지한다.

설치/CI/정확한 소스·모듈·native/복구/보존/ZIP 증거는 작업공간의
outputs/semantic-outlier-review-20261013/에 각각 기록한다. 설치된
Resources의 격리 손상 검사는 합성 저장소에서만 실행하며 원래 저장소를
손상시키지 않는다. 공개 태그·Developer ID/공증·프로덕션 배포와
전체18개 목표, 의미 골드·잔여겹침·물리/호스트/모델/DPO/전체 자원·
최신9도식의 미결은 별도로 유지한다.
