# Alden 검색 평가의 중복 점수와 출처 전달 경계

검색 평가가 같은 자료의 반복을 높은 품질로 계산하던 결함을 수정했습니다. `ndcg_at_k(['a','a','a'], {'a':3}, 3)`은 이전에 2.1309297536을 반환했습니다. 같은 자료는 첫 위치에서만 gain을 얻고, 반복된 위치는 0점으로 남겨 뒤 자료의 순위를 당기지 않습니다. 반환 순위의 중복 ID는 평가 결함으로 별도 집계합니다. Recall은 기존처럼 고유한 정답 자료 수를 사용합니다.

출처가 내부 검색 결과에 있다는 것과 실제 답변 컨텍스트에 전달됐다는 것을 구분했습니다. 기존 `evidence_check_pass_rate`는 내부 ranked 결과의 기대 출처 ID 포함률을 그대로 유지합니다. 새 `context_evidence_check_pass_rate`는 실제 public bundle에서 같은 기대 ID가 확인되는 질의 비율입니다. 개별 결과에는 `public_bundle.missing_expected_evidence_ids`가 남습니다. 두 지표는 출처 ID 포함 여부이며 인용의 의미 정확성이나 원문의 사실 진실을 인증하지 않습니다.

수정 전 최소 반례에서는 내부에 `synthetic:tool:1`이 있고 공개 컨텍스트는 비어 있어도 내부 출처 확인률과 구조 경계 확인률이 모두 1.0이었습니다. 컨텍스트 Recall은 0.0이었지만 출처 전달을 직접 확인하는 지표가 없었습니다. 새 테스트는 내부 확인률 1.0과 공개 컨텍스트 확인률 0.0을 별도로 확인합니다. 정상 구조의 빈 bundle을 구조 오류로 바꾸거나 기대 출처 누락을 숨기지 않습니다.

제공된 두 합성 fixture의 기존 동작을 대사한 결과, `fixture-rrf`에서는 `heldout-relation-time-scope`의 관계 출처와 `heldout-semantic-dense-rescue`의 환불 출처가 공개 컨텍스트에 없었습니다. 이는 다음 검색·컨텍스트 선택 조사 대상입니다. 원인은 예산·순위·필터 경로를 더 확인해야 하며 이번 평가 수정이 제품 검색의 누락을 고쳤다고 주장하지 않습니다. 실제 사람 판단 gold나 생산 자료 평가로 확대하지 않습니다.

부모 작업은 수정 전 세 반례 테스트의 실패와 수정 후 전체 관련 22개 테스트 통과를 확인했습니다. 원문 그래프·카카오 DB·전송 큐·운영 설정을 열거나 바꾸지 않고 제공된 합성 fixture와 임시 폴더를 사용했습니다. E5·생성 모델을 호출하지 않았습니다. 병렬 `chatgpt-web/gpt-6-sol`/`xhigh`의 읽기 전용 검토도 두 결함을 지적했으나, 검토자의 재현 명령은 자동 보안 검토의 보안 상태 판단 불가로 차단돼 실행 증거로 쓰지 않습니다. 부모의 재현과 22개 테스트는 그 차단 통지를 받기 전에 완료했습니다. 검토자의 차단 명령은 재시도하지 않았습니다.

이는 저장소의 개발 평가 도구 변경입니다. 설치 앱은 기존 0.3.102/runtime093b6d1을 유지하며 앱의 검색·UI·모델·데이터를 다시 배포하지 않았습니다. 전체 목표의 실제 원문·동일인·시간·인용 의미 평가와 물리 장치·운영 배포 요구는 계속 남아 있습니다.
