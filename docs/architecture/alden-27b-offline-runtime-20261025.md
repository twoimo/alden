# 고정 27B 오프라인 실행 — 2026-10-25

고정 체크포인트를 작업 전용 경로에 준비하고 실제 MLX 추론을 실행했다.
설치된 Alden은 꺼진 상태를 유지했다. 이 실행은 제품의 상주 모델·설정·게이트웨이를
바꾸지 않으며, 설치 앱의 로컬 추론이나 음성·도구 통합을 검증한 결과가 아니다.
[정제한 실행 기록](alden-27b-offline-runtime-20261025.json)에 원시 기록의 SHA를 연결했다.

## 파일과 실행 환경

`ddalcu/Qwen3.8-27B-MLX-Serve-4bit`의 기존 고정 리비전
`901aa73a1ff5456752c02e55582609e0040ca470`을 사용했다. 기존 manifest의
14개 파일, 18,219,586,850바이트가 현재 게시 메타데이터와 같았고, 다운로드 후와
추론 후에 독립 파일 검증기가 모두 14/14 일치했다. 원래 전역 모델 경로는 복구하거나
다른 양자화로 대체하지 않았다. Flash-Next 3.3bpw 실행 gate도 그대로 남는다.

변환 배포자가 선언한 기반 모델 `Qwen/Qwen3.8-27B`의 현재 리비전
`1d4bf0f2ff6012fd82039f2fa52739d0dd7c60c0`에서 설정 파일을 읽어 게시 blob과
대조했다. 비교한 11개 구조 필드는 일치한다. 이는 가중치 변환의 수치 동등성이나
기반 모델의 전체 계보를 증명하지 않는다. 게시 LICENSE도 blob과 대조했으며,
특정 배포·사업의 라이선스 적합성을 판정한 결과로 사용하지 않는다.

작업 전용 Python 3.12.13 환경에 MLX/MLX-LM 0.32.2, Transformers 5.20.2를
준비했다. 34개 배포 파일의 설치 출처·해시와 `pip check`를 기록했다.
기존 E5 서비스의 환경은 수정하지 않았다. 추론은 OS 네트워크 거부 sandbox와
Python socket audit 아래에서 실행했으며, 별도 거부 probe 통과 후 실행 중 관측된
네트워크 시도는 0이다. 모델 파일의 HTTPS 다운로드는 이 추론 과정과 분리했다.

## 실제 실행 결과와 한계

- 기존 합성 fixture의 train/validation 6쌍은 실제 토크나이저로 prompt/response
  경계와 마스크를 통과했다. 최종 test는 다시 소비하지 않았다.
- validation 3쌍의 실제 응답 36토큰을 teacher forcing으로 채점했다. 동일
  policy/reference를 재사용한 대조이므로 Δ=0, 평균 손실은 ln(2)=0.693147181이다.
  토큰별 log-prob와 집계값을 대사했다. 새 학습·독립 품질 향상 근거가 아니다.
- 새 합성 한국어 대화에서 일정, 후속 장소 질문, 최신 취소 반영은 명시 사실과
  3/3 일치했다. 사람 대화·개인 자료·검색 응답의 대표 gold 평가는 아니다.
- 모델은 실제 `qwen3_coder` parser가 읽을 수 있는 도구 호출을 생성했다.
  정확히 허용된 작업 노트 한 건만 읽었고, 최종 답변에 실제 고정 리비전을 포함했다.
  최종 답변은 128토큰에서 잘려 문장이 끝나지 않았다. 완결된 답변과 제품 도구
  실행 경로의 검증은 미완료다. 이 작업 전용 읽기 adapter는 제품 도구를 대체하지 않는다.

일회 실행의 child 전체 시간은 29.324초, peak process RSS는 17,420,533,760바이트다.
감시 표본의 최소 여유 메모리는 38,736,855,040바이트이고 swap 증가는 0이었다.
40GiB admission, 8GiB OS reserve, swap 증가 128MiB, 공유 작업·비상 중단 감시와
소유 process group의 240초 deadline을 적용했다. MLX의 28GiB 메모리 설정은
allocator 지침이며 OS의 강제 allocation 상한이 아니다. 표본 한 번으로 성능 개선이나
p95를 주장하지 않는다. 기존 collector/E5 process 식별과 설정 파일을 보존했다.
stale managed owner를 인수하거나 초기화하지 않았다.

## 수치 회귀 검사의 호환성

새 환경의 기존 60개 검사 중 하나는 MLX-LM의 과거 MTP 정규화 버그가 지금도
발생해야 한다고 가정해 실패했다. 그 가정만 제거하고 scorer의 folded norm 보존,
raw norm의 한 번 이동, Conv1d 변환, MTP 제거 및 upstream 전역 상태 보존 검사는
유지했다. 실제 선택 형식의 검증도 추가했다. 제품 scorer 코드는 변경하지 않았다.

수정 후 새 환경 60개가 모두 통과했다. 별도로 과거 MLX-LM 0.31.3 코드를 현재
작업 환경 의존성 위에 올린 수치 검사 1개도 통과했다. 이는 과거 환경 전체의 재현이
아니다. 실제 scorer 소스의 MTP 제거를 없앤 격리 변형은 그 수치 검사에서 실패했다.
원본 제품 소스·설치 파일은 변형하지 않았다.

원래 전체18개·ST01–16·모든 후속·Cursor8 gate는 유지한다. 실제 설치/운영,
개인·시간·identity gold, 음성, Flash-Next, 독립 외부 감사와 정상 릴리즈는 이 기록으로
완료 처리하지 않는다. 후보 앱의 canonical receipt는 기존 source7f3에 결속된 상태다.
