# Alden0.3.62 — 밀집 압력과 허브 연결의 밝기

0.3.61의 실제 native 픽셀에서 라벨은 분리됐지만 중앙 투영이 밝게 밀집한 상태가 남았다. 군집 중심으로 당기는 힘만 강화한 실험은 근접 쌍과 가장 가까운 거리의 하위 구간을 악화해 제외했다. 실제 관계 R·저장 벡터 S·군집 판정·ID·권한·가중치와 기존 인력 강도를 유지한다.

같은 공간 셀의 평균 위치에서 각 노드를 분리하는 집계 압력을 추가했다. 셀 경계가 인공적인 밀집 경계가 되지 않도록 계산 단계마다 격자를 옮긴다. 노드당 단계별 최대1번의 밀도 평가를 별도 진단으로 세며, 전체 쌍을 몰래 검사하지 않는다. 충돌131072/단계32/표시2048의 기존 상한, 고정 노드와 미변경 성분을 보존한다.

첫 Map 조회 구현은 소스 계산 중앙값188.40→250.32ms로33% 느려져 채택하지 않았다. CPU 프로파일의 가장 큰 위치는27개 이웃 셀의 반복조회였다. 두 개의32³ direct-slot 배열을 해당 snapshot 동안만 재사용하고, 스프링의 임시 튜플 할당도 없앴다. 압력 기하는 그대로이며 per-frame 작업이나 상주 캐시는 추가하지 않는다.

Overview의 실제 허브는 관계를 지우지 않고 연결 수에 따라 평상시 선의 밝기를 낮춘다. 계산은 자료 갱신 때만 수행한다. 모든 실제 선과 ID를 유지하며 선택한 끝점의 밝기와 상세 뷰는 보존한다. 새96연결 허브 회귀는 기준본에서1실패 후 통과했고, UI476개·최종타입·변경 후 관련40회귀가 통과했다.
