# 추가 원문 관측 검토

설치된 Alden 0.3.27을 유지하며 native OSK의 다음 관측 구간을 네 차례, 각 세 구간씩 이어 읽었습니다. 총 12개 구간의 원문 36개를 현재 게시 corpus에서 정확한 계정·방·log ID·화자 ID로 조회했습니다. 표시 이름은 새로 추정하지 않았고, 읽은 문장의 투자·기술·생활 의견을 사실 승인하거나 실행 지시로 취급하지 않았습니다.

| 대조 범위 | 결과 |
|---|---:|
| 현재 native 구간을 읽고 원문 대조한 관측 | 12개 |
| 정확한 참조 원문 | 36개 |
| 일반 외부 수신 기록 | 34개 |
| 사용자 ID가 붙은 system feed | 2개 |
| 현재 수량과 과거 관측 수량이 달라진 구간 | 2개 |
| 정정 전 원본 바이트 백업 | 12개 |
| native review remaining | 100→88단위 |

모든 수정은 실제 SDK의 유일한 본문 앵커 두 곳에 한정했습니다. 일반적인 '대화 지식' 제목을 원문 관측과 미검증 인용 경계로 명확히 하고, 자동 수량 문장을 역사적 관측값으로 한정했습니다. 현재 수량을 새 상수로 덮어 쓰지 않았습니다. 숫자가 현재 값과 같은 경우에도 관측 시점이 다르면 현재 사실과 구분했습니다.

본래 본문들은 legacy 자동 재생성과 같지 않았으므로 전문 교체를 하지 않았습니다. 인용된 36개 메시지의 내용, 다른 수동 본문, 제목·ID·derived-from 좌표를 보존했습니다. 수정 전 전체 바이트는 opaque `.bin`으로 복사하고 SHA를 확인했습니다. 각 수정은 last-written SHA 대조와 SDK 승인/pin 방어를 통과한 뒤 수행했습니다. 원본 transcript·Raw를 다시 쓰거나 방·화자 이름으로 통합하지 않았습니다.

수정 후 새 SDK 구간과 파일 SHA를 다시 읽고 pinned native MCP read_node의 view_hash를 대조했습니다. 검토 이유에는 정확한 역할·수량·화자 식별자와 인용의 미검증 한계를 남겼습니다. 네 번의 review는 모두 deferred이며 남은 88단위나 전체 Raw 의미 증류를 완료로 간주하지 않았습니다. 사진·링크의 텍스트가 있는 기록을 실제 픽셀/외부 페이지 내용 확인으로 확대하지 않았습니다.

정본 validator는 22 pass·0 fail·0 skipped였고 기존 governance 근거 경고는 유지했습니다. 현행 104개 노트의 검색 색인은 ready로 읽혔습니다. 이전 Raw 파일 5639개의 SHA, 이전 상태의 byte backup 12개, 설정 7개·운영 worker 5개와 설치본 서명을 대조했습니다. 실행 코드는 변경하지 않아 앱을 다시 시작하거나 버전을 올리지 않았습니다. 이번 기록은 새 성능 측정·새 독립 최종 평가·모델 학습 결과가 아닙니다.

개인 이름·메시지 내용·원문 주소·계정 식별자·노트 ID·private snapshot은 공개 문서/배포물에 포함하지 않습니다. 검토 영수증과 원문 대조 자료는 제품 vault와 해당 작업의 비공개 증거에 남습니다. 전체 목표의 나머지 의미/조직 검토, 넓은 독립 품질, 물리 음성/UI, Flash-Next·Dot, 전체 앱 성능·공증/production은 계속 진행 대상입니다.
