# Alden 0.3.64 central density

The accepted 0.3.63 snapshot solver separated close pairs inside individual cells but retained excess concentration across neighboring cells. The new snapshot adds capped pressure only when more than 24 nodes occupy a 3×3×3 neighborhood. Pins, unchanged components, relationship identities and directions, R/S channels, community assignment and the 32-step/131,072-collision budgets remain intact. This changes geometry; it does not establish identity, normalize claims or verify semantic direction.

Candidate lists now retain at most 27 sample references and cumulative lengths instead of copying every sampled ID into each cell. Binary lookup preserves the flattened sample order and quota. Distances between bounded solver points use one square root; general force normalization retains overflow-safe `hypot`. Neighborhood pressure has its own diagnostic count, bounded by nodes × solver iterations. The algorithm runs on snapshots in the existing worker, with no new frame loop.
