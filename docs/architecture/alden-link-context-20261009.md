# Alden 0.3.51: 링크와 파일의 전달 근거

## 수정한 문제

기존 답변 프롬프트는 실제 링크 본문에도 일반 문자열의 1,200자 제한을 적용했다. 전체 발췌가 예산 안에 들어도 뒤쪽 사실을 잃었고, 축소된 범위·해시를 기록하지 않았다. HTML 엔티티가 남거나 제목과 설명만 있는 응답을 본문과 구분하지 않는 문제도 재현했다. 원래 4개 집중 재현의 실패2·오류2는 별도 작업 공간 `outputs/link-context-20261009/reproduction.log`에 보존한다.

새 `alden_link_content.py`는 fetch 권한을 갖지 않는 결정적 파서다. 기존 public-address DNS pinning·redirect·timeout·opt-in·privacy·cancel guard를 유지한다. HTML의 script/style/template/noscript를 실행하거나 읽기 내용으로 넣지 않는다. 엔티티와 명시된 문자 인코딩을 해석하고 PDF/ZIP/gzip 등 다른 형식과 해석할 수 없는 바이트는 일반 본문으로 넘기지 않는다. 링크 PDF 파싱 지원과 파일 PDF 파싱 지원은 같은 범위가 아니다.

## 출처와 실제 읽은 범위

원문은 최대 1,000,000바이트, 텍스트는 UTF-8 경계를 지킨 최대 16,000바이트다. SHA256은 수신 원문과 추출/전달 텍스트를 따로 기록한다. 조회 시각은 게시 시각이나 현재 효력의 증명으로 쓰지 않는다. `evidence_id`는 URL·원문 해시·보조 추출 텍스트 해시에 연결한다.

읽은 범위는 `page_text`, `metadata`, `captions_excerpt`, `readme_excerpt`로 구분한다. 페이지 텍스트의 존재는 로그인·작성자·요청 대상 일치나 전체 콘텐츠 확인을 증명하지 않는다. 자막과 README 보조 해시는 추출 텍스트 기준이며 전체 보조 원문의 해시로 설명하지 않는다. 16KB 상한과 예산 축소, 제한된 자막/README 발췌를 부분 읽기로 표시한다.

링크 발췌는 보조 대화보다 먼저 프롬프트에 예약한다. 필요한 축소는 출처 ID를 보존하며 전달 텍스트 해시·바이트·잘림을 갱신한다. 누락되거나 변조된 근거는 추론 전에 막는다. 모델에 전달된 근거와 모델이 실제 인용한 ID를 구분하고, 모두 사용했다고 자동 인용하지 않는다. 범위·부분 읽기·자료 속 지시 금지는 축소되지 않는 시스템 규칙에도 넣는다. 파싱 오류와 시간/용량 제한은 원인 코드로 남긴다.

기존 파일 원문 해시·정확한 chat/log/author/attachment 귀속·파싱·부분 읽기·현재 턴/취소 경계는 유지한다. 입력 파일은 명령이나 외부 전송 권한으로 해석하지 않는다.

## 검증과 전달 경계

뒤쪽 사실 보존, 명시적 잘림, 여러 출처 ID, 제목만 있는 페이지, 자막/README 발췌, 문자 인코딩, 엔티티, 바이너리 오인식, 변조/누락 방지, 파일 파싱·사진 후속 질문·대화 전환/취소·워커 패키징을 검증한다. 새 파서는 Tauri와 Rust의 정확한 리소스 목록 및 불변 워커 준비 목록에 함께 포함한다. 최초 Python/Rust 리소스 대사 실패는 누락된 Rust 목록을 보완해 해결했고 로그를 보존한다.

설치 검증은 실제 설치 Resources의 파서와 Gemini Flash high를 사용한 합성 긴 링크 본문·native PDF 내용·후속 질문을 확인한다. 실제 public 링크 취득 결과는 별도 영수증으로 기록한다. 합성 콘텐츠와 격리 파이프라인 검증을 실제 카카오톡 수신·발송·물리 입력으로 확대하지 않는다. 기존 운영 워커는 잔여 감독자 증빙 오류로 활성화되지 않았으며, 전체 미디어 수신 경로·여러 host·물리 음성·정식 릴리즈·프로덕션은 전체 TODO에 남긴다.
