Installed 0.3.106 did not treat “저장된 하나저축은행 IT기획 공고를 근거로
지금 지원 가능한지 알려줘” as a knowledge lookup. Adding the generic word
“자료” routed the same intent. Conversely, a new storage request containing
“자료” could trigger an unnecessary lookup. These are request-routing defects,
not evidence that the original collection is empty.

## Routing and current-turn precedence

The shared typed/voice reader recognizes explicit retained storage/collection
language, a source object such as 공고/게시물/문서/파일/영상/링크, and a lookup
request. A request to store the current input and an explicit refusal to
search/read take precedence. That veto also applies to a followup beginning
with “그/그러면”; earlier lookup history cannot override the current refusal.
The existing conversation, permission, cancellation and quoted-role boundaries
remain in place. This does not implement a source write or claim that a request
to remember text created an OSK node.

## Clock, observation and validity are separate

Each selected model context carries `query_clock` under `host-query-time-v1`,
with explicit UTC and the basis `host_query_time; not source_date_or_claim_validity`.
The value is generated by the host; a retrieved record cannot supply it. It
does not replace the user's requested past/future period, source publication,
collection time, valid period or supersession evidence. Original dates, IDs,
versions and source proofs remain unchanged. Body deadlines are not parsed
into automatic expiration, identity merges or graph deletion.

When the 8,000-character quote budget removes some records, metadata reports
partial coverage and the model receives a warning against claiming to have
reviewed all records. Full budget removal retains the existing explicit
budget-failure path. Body truncation and source roles remain separately marked.

but returned `response.incomplete`, `incomplete_reason: max_output_tokens`.
The former 1,024-token cap had insufficient room for this high-reasoning

standard requests retain 1,024. Token-limit incompletion remains a failed
turn, with `routed_llm_reply_truncated` preserved through generation evidence

provider availability. Model, effort, input/response byte limits, cancellation,
no automatic retry and no silent model substitution remain unchanged.
