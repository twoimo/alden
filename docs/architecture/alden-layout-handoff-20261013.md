# Alden 0.3.90 — 비동기 배치의 이전 좌표 기준

같은0.3.89 설치본에서 다음 페이지를 두 번 읽었을 때 120개 물리 대상의 계산된 anchor가 최대0.012875807세계 단위 달랐다. 같은 관계 배치 R가 먼저 완료되고 본문 벡터 유사도 S가 늦게 도착하는 동안, 프레젠테이션/물리 이동 좌표와 완료된 solver 좌표가 다음 계산의 이전 기준에 섞였다. 자료·관계는 그대로여도 도착 타이밍이 위치에 영향을 줬다.

0.3.90은 완료된 solver checkpoint를 다음 계산의 기준으로 사용한다. 현재 선택한 pin에는 사용자가 보는 현재 위치를 적용한다. 화면은 기존 물리 엔진과 위치 전이로 현재 위치에서 새 목표를 향해 움직이며 source/renderer Map을 덮어쓰지 않는다. 같은 완료 R와 최종 R/S를 사용한24개 합성 실험은 타이밍에 따른0.0054538차이를 재현했고 후보에서0이 됐다.

캐시는 현재 view의 prior/provisional만 사용한다. pin의 ID뿐 아니라 현재 좌표도 재사용/진행 요청 판단에 포함하고, 노드 철회와 명시적 변경을 반영한다. 현재 좌표가 없거나 비유한 pin은 거부하며, 실패한 같은-key 복원을 settled로 표시하지 않는다. 버전/R/S·취소·세대·만료·clear의 보호 조건을 유지한다. 공간 기억과 별개로 사람 동일성·원문 의미를 검증한 것으로 취급하지 않는다.

## 실제 검증 범위

초기3개와 독립 검토 후4개 회귀가 변경 전에 실패하고 수정 후 통과했다. 전체 UI822개·타입·native137개·엄격한 Clippy를 확인했다. WebGPT6/xhigh는 실제 route를 확인한 새 세션에서 제공 코드를 정적으로 검토했으며, 전체 앱/런타임/원문 의미를 독립 평가한 것으로 확대하지 않는다.

진단은 원문/ID 없이 현재 전체 solver target을 익명 좌표로 캡처한다. 기존64행 분할·16,384바이트 응답 상한을 유지한다. 후보 next-page 두 실행의 일반/작은 창에서 전체1,984개 target이 bit-exact 일치했다. 120개 물리 대상·관계 구조도 일치하며 전체 가시성·코어 겹침0·정착·2초 추가 렌더0을 확인했다. 통합 첫 페이지2,048개의 두 창 크기도 기존 겹침/정착 검사를 유지했다.

이 결과는 기록된 완료 R→동일 S·동일 source 조건의 검증이다. R가 완료되기 전에 취소되는 모든 순서, 더 넓은 실제 source/history·모든 규모의 동일 pose, 픽셀·전체 앱 CPU/GPU/RAM/배터리와 물리 입력을 입증하지 않는다. 원문 의미/정규화/중복/이상치·GraphRAG 기본 top3·다중 호스트·모델/DPO·현행 도식·정식 서명/공증/프로덕션 등 전체18개 목표는 미결 조건을 유지한다.

작업 근거는 outputs/page-layout-handoff-20261013/에 보존한다. 설치·복구/설정/데이터 대사, 현재 설치본의 반복 target 비교, 화면 검수, PR/CI와 ZIP은 별도 영수증으로 확인한다. 기본 Gemini Flash/high/manual 설정과7개 수집 대상 및 모델 프로세스를 유지하고 새 무거운 추론을 시작하지 않는다.
