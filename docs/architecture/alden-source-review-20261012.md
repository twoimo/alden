# Alden 0.3.73 — 출처 검토, 가역 묶음과 그래프 전달

기억 정리에서 허용된 현재 자료를 검색·비교하고 같은 지식으로 묶은 표시를 되돌린다. 원래 자료·버전·관계·검색 기록은 보존한다. 이는 사용자가 확인한 가역 표시 결정이며 실제 엔터티 동일성이나 원문 의미 정답을 자동 인증하지 않는다. 프로젝트·대상별 출처 맥락을 표시 투영에서 유지한다.

## 적용과 복구 계약

처음 선택한 자료를 대표로 삼는다. 비교 후 이유와 같은 지식 확인이 모두 있어야 적용된다. 검토 중 선택·이유가 바뀌거나 오래된 응답이 도착하면 확인을 초기화한다. 결과를 놓친 요청은 같은 요청 ID로 재확인하고 새 결정을 중복 만들지 않는다. 읽기 실패는 성공으로 표시하지 않는다. 되돌리기는 별도 두 단계 확인을 사용한다.

원본 ID와 현재 버전·권한·관계, 저널 UUID와 선택 자료의 저장 이벤트를 결속한다. 다른 자료의 갱신과 선택 자료의 교체·재수집을 구분한다. 활성 묶음은 프로젝트마다256개를 넘지 않으며 적용 전과 쓰기 트랜잭션 안에서 다시 확인한다. 첫 SQLite 백업은10초·진행·정합성·fsync 보호를 사용하고 불완전한 소유 백업만 정리한다. 보호 규칙을 통과하지 못한 결정은 적용하지 않는다.

본문은 기존 `source-content-evidence-v2`를 따른다. 검증된 현재 보관 기록의 `localOriginalText`가 있으면 사용하고 그 외에는 저장 본문임을 표시한다. 원본 전체 파일을 읽었다고 주장하지 않는다. 본문이 없거나 잘린 비교와 메타데이터·미열람 안내만으로 확인하지 않는다. source 계보와 버전이 바뀌면 이전 표시 결정이 유효한 것으로 남지 않는다.

## 실제 전달 회귀와 측정

출처 맥락 추가 후 개요1984노드/3789관계의 JSON이4,560,786byte가 되어 네이티브4MiB상한을 넘었다. 앱은 수집 그래프를 읽지 못하고 기억 자료106개만 표시했다. 단순 공백 압축도4,361,156byte로 상한을 넘었다. 실패 캡처와 진단을 별도 보존했다.

`display-source-context-v1`은 표시 자료의 target/version/label과 정확히 같은 맥락만 참조로 전달한다. 다른 맥락·추가 필드는 그대로 전달하고 UI에서 모든 필드를 복원한다. 알 수 없는 형식·충돌 필드·누락된 기준은 거절한다. 실제 Python→TypeScript 깊은 대조에서 모든 필드가 동일했고4,013,129byte로 기존4,194,304byte상한 안에 들어왔다. 원본·출처·관계·수량과 전달 상한을 줄이지 않았다. 이는 전달량 관측이며 앱 FPS/GPU/배터리·일반 지연 개선율이 아니다.

## 실행 검증과 설치

실행 소스는 `ef7ef9e04e05d1dee9929e90fc8379a17142b8fe`다. 최종 pinned Python155, UI728/타입, native131/strict Clippy가 통과했다. 준비 런타임 의존4모듈 누락은3실패로 재현하고 목록을 보완해 전체 packager13검사를 통과했다. 운영 worker 활성화나 전송 큐 변경을 뜻하지 않는다. [소스 CI38189656104](https://github.com/twoimo/alden/actions/runs/38189656104)의 네 작업도 성공했다.

후보·설치본 각각 실제 네이티브 읽기 전용14상태/28PNG가 성공했다. 개요에는1984수집자료와64기억 투영, 총2048표시 노드/3789관계가 돌아왔으며 전체 저장 규모와 표시 페이지를 구분한다. 두 크기의 전체 그래프·품질 화면을 직접 확인했다. 검은 배경·작은 점·가는 선·관계 거리 색·한 줄 상단과 기존 위치·라벨 보호를 유지한다. DOM 표본8라벨의 겹침/잘림0은 해당 관찰 범위이며 전체3D군집의 의미 정답이나 물리 Retina 증거가 아니다.

새 private synthetic collection과 incognito WKWebView를 사용하는 명시적 `--audit-own-entity-review`에서 실제 메뉴 CLI/SQLite/화면 버튼으로 비교→묶기3→2→되돌리기3을 두 크기씩 검증했다. 후보4.038초·설치3.981초는 각각 관측 시간이며 성능 전후 비교가 아니다. 각 실행의 원본12표 digest, 원래 관계2개, 최종 활성 묶음0과 결정 이벤트4개가 확인됐고12PNG를 직접 검수했다. 운영 자료에 시험 병합이나 모델 추론·메시지를 실행하지 않았다. 일반 읽기 검수는 이 쓰기 경로를 허용하지 않는다.

## 남은 조건

실제 사람 판단과 원문 의미 gold·동명이인·철회/충돌·전체 힘/방향 군집 정확도·여러 호스트·물리 음성/입력/Retina·대표 전체 앱 자원·모델/DPO·최신9도식 대사·정식 DeveloperID/공증·태그/프로덕션 배포는 별도 미결이다. 참고 벤치마크 수치를 Alden 결과로 사용하지 않는다. 원래 편집2파일·별도 후보·설정·모델·큐·보호 원문을 유지한다.
