# Eight retained videos gain actual timestamped captions

Eight existing empty-body videos from the two already declared channel scopes were selected before acquisition results. The installed Aside native YouTube methods returned metadata, track declarations and timestamped Korean captions for all eight. The installed Alden snapshot validator accepted each result. These are bounded source reads, not a wider account/channel survey, visual-video analysis or independent truth verification. No model agent, new account or credential extraction was used.

The inputs contain 113,471 caption characters and 118,470 description/caption characters in total. The native interface did not return a stable uploader ID for these eight; the prior channel membership is explicitly retained as declared context and is not converted into an acquired author identity. No caption text, new video IDs or private input files are included in this public document.

This does not assert byte identity for live database/WAL/SHM files or every external original file.
