# Alden 지식 그래프 알고리즘 점검과 개선 방향

작성: 2026-10-19 KST. 실행 소스: `c3871f3aa203bebb9a8b0d5bba6b9f3fc908b0b8`, 설치 버전 0.3.153. 이 문서는 추가 연구를 위한 **잠정 방향**이다. 기존 전체 목표 18개와 후속 요청을 대체하지 않는다.

현재 결론은 **원문·권한·실행 예산을 보존하는 장치는 갖췄지만, 의미 군집과 실사용 검색 품질까지 정상 또는 세계 최고 수준으로 검증된 상태는 아니다**. 화면 가독성 개선, 단위 테스트, 실제 원문 해시 확인은 각각 유효한 증거지만 의미 정답 평가를 대신하지 않는다.

## 1. 확인한 현재 구조와 경계

| 계층 | 현재 구현·근거 | 확인된 경계 |
| --- | --- | --- |
| 원문·버전 | CollectionStore, 원문 SHA, source_version, 철회·시간·권한 확인 | 원문이 정확하게 보존됐다는 사실과 원문 주장의 진실성은 다름 |
| 정규화 | 수량·시간·출처 정책, NFC/공백 표시 중복 제거, 출처가 확인된 숫자 꼬리 표시 분리 | 숫자 꼬리는 의미 미확인 후보. 다른 날짜·단위·반대 주장·동명이인을 자동 삭제/병합할 근거가 아님 |

| 군집 | `semantic-layout.ts`: 구조/의미 차수 분리, 끝점 의미 차수 4, 의미 스케일 .25, 연결 요소별 모듈러리티 local move 최대 8회 | Leiden 구현·수렴 보장으로 부를 수 없음. 의미상 올바른 군집·연결성·해상도 안정성 보장 없음 |
| 배치 | 스프링·밀도/충돌 제한·핀·캐시·방사 투영, 2048 표시 노드 예산 | 위치는 여러 목적함수의 절충. 모든 강한 cosine 쌍의 거리가 항상 더 짧다는 보장 없음 |
| 라벨·줌 | 저장된 라벨의 category/단어 수/차수/출처 다양성 휴리스틱, 화면 충돌 제거·줌 예산 | 사용자의 업무 관련성 또는 각 군집의 대표 주제라는 정답 보장 없음 |
| 검색 | BM25와 Dense 순위 RRF·권한/시간 필터·출처 전달 | 기존 27질의 자료는 합성. 높은 점수로 실제 E5나 사람 검색 만족도를 주장할 수 없음 |

‘힘과 방향이 같은 것끼리 모인다’는 표현은 다음처럼 구체화해야 한다. **임베딩 유사도**, **출처가 있는 관계**, **화면 배치력**을 별도 채널로 유지한다. 배치의 힘은 사실 관계나 동일성의 증거가 아니다. 관계의 방향·유효 시각은 저장된 간선에, 의미 유사도는 모델/텍스트 버전에, 화면 거리는 화면 설명과 측정에 결속한다.

30개 모두 유한 좌표·같은 ID의 입력 배열 역순 재현성이 통과했다. 단, ID를 일대일 치환한 동일 그래프에서는 독립 4블록 분할끼리의 ARI가 .3507~.5666이었다. 입력 배열 안정성과 이름 치환에 대한 군집 안정성은 별개의 문제다. 좌표는 ID 기반 seed를 사용하므로 이름 치환 후 동일 좌표를 요구하지 않았다.

원시 입력 간선의 합집합 기준으로 분리된 군집은 이번 30개에서 관측되지 않았다. 이는 필터링된 실제 군집 그래프의 연결성 보장이나 형식적 증명이 아니다. 5개 seed의 탐색 실험으로 모집단 품질·통계적 유의성·실제 의미 오류율을 주장하지 않는다.

원인 후보는 코드의 `componentVolume`을 사용하는 분모, 전역 gamma/계층 목표 부재, 제한된 local move와 ID 순회다. 분모를 전역 값으로 되돌리는 패치는 무관한 연결 요소의 간선 수에 기존 군집이 영향을 받게 할 수 있다. 반례만 보고 그 패치를 채택하지 않는다.

기존 합성 검색 평가도 현재 소스에서 재실행했다. 23엔터티/3관계/27질의 중 BM25 Recall@3 및 nDCG@3=.9583, 고정 합성 Dense 순위를 넣은 fixture-RRF=1.0000, 금지 문맥 누출=0이었다. heldout 15질의도 같은 합성 자료 집합에 속한다. 이는 제품 필터·순위 융합의 회귀 근거이며, 실제 Dense 모델 비교·독립 사람 gold·세계 최고 성능 근거가 아니다.

## 3. 목표와 선택할 아키텍처

목표는 **같은 질문과 자료에서 근거를 더 정확히 찾고, 잘못된 통합을 막으며, 사용자가 줌과 이동을 해도 이해를 유지하는 지식 작업 도구**다. ‘세계 최고’는 전 세계 제품 대비 우승으로 선언하지 않는다. 공개된 비교 범위, 고정된 자료·모델·예산, 재현 가능한 결과가 있어야 경쟁력을 주장한다.

1. **ADR-A01: 하나의 논리 그래프, 분리된 증거와 투영.** 원문/버전, 주장, 개체, 관계, 유사도, 커뮤니티, 화면 투영을 ID로 연결한다. 각 투영에 알고리즘/파라미터/입력 해시를 기록한다. 여러 출처를 한 화면에 통합해도 권한·출처·상충·시간 경계는 보존한다.
2. **ADR-A02: 구조와 의미의 다중 채널 + 명시적 군집 해상도.** 현재 휴리스틱을 baseline으로 남기고 Leiden+modularity, Leiden+CPM 및 구조/의미 채널 ablation을 오프라인 비교한다. gamma와 계층은 dev에서만 선택한다. Leiden의 연결성 보장이 의미 정답까지 보장하는 것은 아니다. Python reference가 이겨도 TypeScript/Rust 소비 경로의 동일성·예산 검증 전 교체하지 않는다.
3. **ADR-A03: 의미를 보존하는 정규화와 검토 가능한 통합.** 숫자·단위·날짜·고유명·부정·범위를 구조화하되 원문 span을 유지한다. 같은 글 재수집, 같은 뜻의 주장, 같은 개체를 각각 평가한다. 불명확한 경우 후보로 남기고 버전/CAS·되돌리기·출처 전달을 요구한다.
4. **ADR-A04: 계층에 따른 semantic zoom.** 전체에서는 실제 커뮤니티를 설명하는 주제·근거 범위, 중간에서는 하위 주제·대표 개체, 근접에서는 원문 제목과 개별 관계를 보여준다. 제목을 생성하면 사용한 문장·출처 span을 연결하고 근거 부족 시 기존 제목/라벨로 제한한다. 고정 단어 수·차수만으로 유용성을 판정하지 않는다.
5. **ADR-A05: 질문 유형에 맞는 검색.** 사실 조회는 BM25/Dense/hybrid, 관계 질문은 제한된 graph expansion, 전체 주제 질문은 출처가 있는 community summary를 비교한다. GraphRAG라는 이름만으로 모든 질문에 graph expansion을 강제하지 않는다. 요약의 갱신·철회·충돌 전파도 검증한다.
6. **ADR-A06: 검증을 통과한 구성만 승격.** 기존 모델·임계값·그래프를 보존하고 새 알고리즘은 shadow/명시 선택으로 비교한다. source hash나 권한이 바뀌면 파생 캐시를 무효화한다. 계정/모델/유료 용량의 임의 변경은 하지 않는다.

사람 정답은 구현 모델의 출력으로 채우지 않는다. 평가자는 알고리즘 이름을 숨긴 자료를 보고, 최소 20% 이중 판정과 모든 불일치 재판정을 수행한다. 동의도와 제외 기준을 기록한다. 300질의·600쌍은 첫 단계 제안이며 충분성은 실제 분산·검정력·slice 크기와 교차 감사에서 재검토한다. 동일 질의 반복이나 유사 문서 누출로 표본을 부풀리지 않는다.

## 7. 1차 자료와 적용 범위

- [Leiden 원 논문](https://arxiv.org/abs/1810.08473): 연결된 커뮤니티의 보장. 의미 정답이나 Alden 소비 경로의 성능 보장이 아님.
- [CPM·resolution-limit 논문](https://arxiv.org/abs/1104.3083): 목적함수/해상도 대안. gamma 선택·가중치 채널 보정의 면제 근거가 아님.
- [GraphRAG 원 논문](https://arxiv.org/abs/2404.16130): corpus 전체 질문에 대한 community summary 접근. 모든 사실 검색의 우월성을 주장하지 않음.
- [공식 GraphRAG 검색 개요](https://microsoft.github.io/graphrag/query/overview/): local/global/DRIFT 질문 유형 비교의 출발점.
- [BEIR 공식 구현](https://github.com/beir-cellar/beir): 다른 작업과 자료를 통한 검색 비교. 공개 검색 benchmark 결과를 개인 자료의 정확성으로 대체하지 않음.
- [GraphRAG-Bench 연구 프로젝트](https://graphrag-bench.github.io/): graph construction→retrieval→generation 단계별 평가 후보. 데이터 라이선스·언어·작업 적합성 확인 후 재현.
- [W3C SHACL](https://www.w3.org/TR/shacl/): schema/constraint 검증의 참고. Alden은 RDF가 아니므로 당장 저장소를 바꾸거나 의미 진실성을 검사한다고 부르지 않음.

각 논문·공식 문서는 이번에 열람했다. 최신 세계 순위 전수 조사나 이 알고리즘 후보들의 Alden 설치 성능 비교를 완료한 것은 아니다.

실행 도구 경로 보충: 감사 전용 코드는 build receipt가 수집하는 `scripts/` 대신 `docs/audits/`에 둔다. 제출 당시 계획/도구는 `outputs/algorithm-audit-20261019/audit-plan-submitted.md`, `audit-helper-submitted.ts`에 보존했다. 상대 import와 재현 명령 경로만 바뀌며, 실행 소스·알고리즘·실험 조건·판정은 같다. 제출된 bundle SHA는 변경하지 않는다.
