# 우주 관제형 지식 터미널 후보

2026-10-20 사용자 방향에 따른 0.3.190 후보다. 기존 전체 18개 목표와 데이터·권한·출처 계약을 유지한다. 외부 교차감사와 정식 릴리즈 검증은 아직 완료되지 않았다.

## 사용자에게 보이는 변화

깊은 남색의 실제 3D 그래프, 확장 창의 두 보조 투영, 하단 6개 패널을 한 화면에 둔다. 세계수·뇌 형상이나 가짜 전투 활동은 사용하지 않는다. 상단 검색과 필터는 유지하고 터미널을 접을 수 있다. 작은 창에서는 하단 패널을 가로로 넘기며 읽는다.

| 패널 | 실제 근거와 범위 |
| --- | --- |
| INGEST | 선택 프로젝트·출처·대상·검색·기간의 최근 처리 이력에서 원문별 최신 단계 |
| LINKED | 현재 지도에서 선택한 지식의 실제 방향·관계·이웃. 클릭하면 같은 지도에서 선택 |
| f(x) | 현재 표시한 지식의 실제 수정 날짜별 분포. UTC, 기록이 있는 최근 14개 날짜, 미상/미래 날짜 별도 |
| SECTORS | 현재 표시한 지식의 저장된 유형별 개수. 의미 군집·신뢰 점수가 아니다 |
| CHORD | 현재 표시한 유형 내부와 서로 다른 유형 사이의 실제 관계 수. 방향을 보존하고 주요 6경로 중 3개를 목록으로 표시 |
| TAIL-F | 최근 영속 처리 이력. 추적을 끄면 읽던 기록을 유지하고 새 기록을 별도로 알림 |

INGEST/TAIL-F는 수집 이력 범위, 다른 집계는 현재 표시 범위로 명시한다. 그래프 유형·관계 필터가 있을 때는 이력도 표시 노드 ID로 제한한다. 이력은 기존 collection-history API의 최근80개를 읽고 중복 sequence를 제거한32개를 보유하며 화면에는12개까지 표시한다. 전체 기록의 보존·필터·페이지 탐색은 기존 기억 정리 화면이 담당한다. 자료 발견·형식 확인·저장·검색 반영을 서로 다른 상태로 표시하고, 기존 자료 유지 이벤트를 새 지식 추가로 표시하지 않는다.

## 소유권과 수명주기

기존 CollectionGraphController가 갱신과 프로젝트/필터/선택을 소유한다. 새 패널마다 타이머나 이벤트 구독을 생성하지 않는다. 기존 스냅샷 갱신 시 이력을 한 번 조회하고 범위·가시성 epoch로 늦은 응답을 배제한다. 자동 갱신 중지는 그래프·활동·패널 조회를 멈추며 숨김/복원 뒤에도 사용자가 재개하기 전까지 유지한다. 운영 전체의 비상 중단과 구분된다.

보조 화면은 메인 렌더러의 실제 표시 좌표를 Canvas2D로 투영한다. 별도 물리 solver·WebGL renderer·연속 렌더 루프가 없다. 배치/카메라가 정착한 알림과 화면 크기·선택·데이터 변경에 반응한다. 노드 좌표는 새로 만들지 않고 관계는 실제 현재 간선 중 최대300개만 그린다. 이 제한과 표시 범위를 화면에 적는다.

집계는 철회·유효기간 밖·고아 관계를 배제하고 정확히 같은 입력의 반복만 중복 제거한다. 서로 다른 관계 방향·유형·근거·시간·가중치는 유지한다. 이 표시 계층의 방어를 원본 정규화·엔터티 병합 완료로 세지 않는다.

## 참고와 미완료 감사

사용자 제공 이미지의 정보 밀도·패널 배치를 참고해 직접 구현했다. [Bloomberg terminal clone](https://github.com/feremabraz/bloomberg-terminal/tree/d53714efca546ed90bf4396383d1459cc962de69)과 [FinceptTerminal](https://github.com/Fincept-Corporation/FinceptTerminal/tree/3d8617cae3f13c93874d4bee4fb0f2846e9c83bc)의 공식 README와 revision을 고정했고, 코드나 금융 시뮬레이션은 가져오지 않았다. 다른 프로젝트의 성능 수치를 Alden의 성과로 사용하지 않는다. 기존 Graphify 판정도 별도로 유지한다.

ChatGPT thesis 요청은 공유 FIFO request9f9d8266d96bc8b3330ef9b4로 대기 중이다. 실제 보고서, Gemini adversarial Deep Research, ChatGPT reverse verification과 판정 매핑은 미완료다. 현재의 2D 투영 선택은 되돌릴 수 있는 구현 후보이며 최종 성능 우위가 검증된 설계가 아니다. 다음 연구 실행 전 공개 최종 소스와 이번 후보의 차이를 기존 요청에 결속해야 한다.

## 검증과 전달

자동 검사, 네이티브 렌더, 설치 앱, 물리 조작·GPU/FPS·배터리, 외부 감사, 정식 배포를 구별한다. 현재 측정/실행 증거는 작업 루트 outputs/space-terminal-20261020에 보존한다. 확장·기본·작은 창의 실제 저장 그래프를 읽는 네이티브 감사는 원본에 쓰지 않고 별도 창에서 수행한다. 개발 인증서 서명은 정식 Developer ID 공증과 다르다. 기존 로컬 고정 서명 프로필을 사용하고 미래 macOS 권한 팝업이 전혀 없다고 보장하지 않는다.

## 0.3.191 — 같은 유형의 연결과 배경 보정

사용자 화면에서 CHORD가 비는 문제를 점검하면서, 같은 저장 유형 사이의 실제 간선을 집계에서 제외하던 조건을 재현했다. 같은 유형의 두 실제 노드가 연결된 경우도 집계하고 내부 연결 곡선과 실제 건수를 표시한다. 이 곡선은 유형 안의 연결이며 개별 노드의 자기 관계를 새로 생성하지 않는다. 실제 간선이 없는 범위의 빈 상태는 유지한다. 패널 구분선도 명확히 한다. 그래프 배경은 청색 기조를 유지하면서 넓은 밝은 영역을 줄이고 깊은 남색으로 조정한다.

CHORD 패널과 내부 SVG가 같은 CSS 이름을 사용해 차트의 고정 높이 88px가 패널 전체에도 적용됐다. 차트 이름을 분리하고 패널 경계는 반투명 1px 테두리 대신 패널 전체 높이의 불투명 2px 그리드 간격으로 표시한다. 본문 스크롤은 패널 안에 유지하고 좁은 창에서는 전체 패널을 가로로 넘긴다.

사용자 요청에 따라 QA 중 Alden을 전면으로 올리거나 떠 있는 네이티브 감사 창을 띄우지 않는다. 일반 UI·레이아웃 검사는 창이 없는 브라우저 렌더링과 기존 테스트로 수행한다. 최소화된 실제 앱의 가시성·입력·GPU 동작은 이 검사로 입증되지 않으므로 별도 미검증으로 남긴다. 이번 요청 뒤 네이티브 창 제어 조회는 시간 초과되어 기존 창의 최소화 상태를 확인하지 못했다.
