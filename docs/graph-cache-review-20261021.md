## Snapshot identity and time

The driver previously serialized node, relation and S-pair arrays in their received order. A reorder-only redraw therefore missed its pending/completed cache despite equivalent inputs. The key now sorts serialized copies within the solver's input caps. Above a cap, order determines the admitted prefix and remains significant. Duplicate node IDs retain order sensitivity. Layout category is included so a changed category cannot accidentally reuse the old geometry label cache. Source versions, authority, pins, R/S values and relation validity remain part of identity; source arrays are unchanged.

Each dispatched job also carries the same finite `nowMs` used for its key's relation-validity decisions. The worker consumes that timestamp and rejects a missing/nonfinite clock. The wall clock itself is not a cache discriminator; only the validity state is. Existing main-thread checks still discard a reply if an edge boundary passes before application. Thus freezing the calculation time does not permit an expired result to publish.
