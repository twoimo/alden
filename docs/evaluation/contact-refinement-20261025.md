## Behavior and authority

The previous producer improves numerical-neighbor recall, but its saved-graph
cold layout still has more very close world/projected pairs. A constant lower
bound on imbalanced R hub stiffness also attracts many unrelated spokes inward.
The new geometry attenuates that existing normalized R contribution by
`sqrt(min(endpoint_degree)) / sqrt(max(endpoint_degree))`. Taking roots before
ratio division retains a subnormal numerator. R records, directions, evidence,
versions, rendering and S cosine scores are unchanged. This is a layout heuristic,
not a semantic-equivalence test or a factual merge.

A final geometric contact phase uses the existing 0.14 clearance after the
bounded spring solve and coincident-origin correction. For m movable points,
`B = min(16384, 8*m)` checks are reserved from the existing131072 shared cap.
The spring/collision pass gets the remainder. Four contact passes operate on
frozen points and accumulate directed corrections before applying them. Each
position still goes through world/pin admission and the cached-prior trust
region. Fixed endpoints do not move. Unchanged snapshots still skip solving.

This follows the position-projection principle described by
[Mueller et al., Position Based Dynamics](https://matthias-research.github.io/pages/publications/posBasedDyn.pdf).
It is a bounded sampled adaptation, not that paper's complete solver or a claim
that every contact is resolved. Contact tests, passes, moved/skipped nodes and
sampling truncation are reported. Pinned conflicts, unsafe extreme grid frames,
limited samples and opposing constraints can leave unresolved geometry.

The sample cursor advances by visited candidates, including self. A fixed stride
of17 can repeatedly select the same candidates in a17-member neighborhood; an
actual-source broken variant reproduces that omission. Ordinary bounded points
use exact integer keys in a64-cube grid. Admitted cell coordinates are within
[-30,30], so their adjacent cells stay within[-31,31] and each packed base64 digit
fits without a key collision. Other finite frames use sparse string keys;
unsafe integer grid coordinates are explicitly skipped. This key argument is
not a floating-point contact-completeness proof.

For admitted N and four passes, grid/neighborhood work is bounded by O(27*N)
per pass and the separately capped distance tests. Neighbor lists replicate each
point into at most27 occupied neighborhoods. This does not make the whole
community/layout algorithm linear or support unbounded graph size.
