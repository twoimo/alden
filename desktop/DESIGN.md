# Alden desktop design contract

## 0.3.79 — 페이지 전환과 정착된 공간 기억

새 ID의 임시 표시 좌표를 이전 정착 위치로 해석하지 않는다. 완료된 ID와 사용자 고정 위치를 보존하고 복귀한 페이지의 배치를 재현한다. 검은 배경·절제된 실제 관계 색·작은 점과 가는 선·한 줄 상단을 유지한다. 투영된 점 코어의 겹침은 명시적 검수 요청에서만 집계하며 고객 화면에 기술 조작 요소를 추가하지 않는다. [실제 재생·화면 측정 경계](../docs/architecture/alden-page-layout-20261012.md).

## 0.3.78 — 의미 배치의 메모리 여유

동일한 현재 그래프 참조와 집계를 유지하면서 필요가 끝난 전체 응답을 벡터 검증 전에 해제한다. 기존 예산 실패를 완료로 표시하거나 오래된 배치를 재사용하지 않는다. 같은 결정적 CLI 출력과 전체 프로세스 peak RSS를 대조하며, 설치 화면의 적용 여부는 별도로 검수한다. [실제 메모리 측정과 검증 범위](../docs/architecture/alden-affinity-memory-20261012.md).

## 0.3.77 — 의미 배치 후보의 비교 참여 범위

현재 허용 프로젝트와 검증된 본문의 기존 벡터만 비교한다. ID 순서의 앞부분에 연결 기회가 집중되지 않도록 프로젝트별 순환 비교를 사용한다. 참여한 노드 수와 전체 비교 쌍의 범위를 구분하며 부분 결과를 의미 정답으로 표시하지 않는다. 새 기술 조작 요소 없이 내부 진단에서 비교 방법·범위를 확인한다. 실제 관계 색·한 줄 상단·작은 그래프 카메라와 원래 자료를 보존한다. [실제 고정 입력과 검증 경계](../docs/architecture/alden-semantic-sampling-20261012.md).

의미 배치 완료는 실제 표시 그래프와 컨트롤러 결과를 대조한다. 현재 그래프에서 배치가 빠지면 이전 완료 상태를 재사용하지 않으며, 새로 검증된 동일 결과도 현재 그래프에 다시 적용한다. RAM 예산으로 적용이 불가능하면 저장된 관계 배치를 유지한다. 설치본의 작은 창에서 관측된 예산 실패와 중앙 집중을 검수 한계로 기록한다.

## 0.3.76 — 작은 그래프의 점 가독성

현재 표시 노드가 1~24개이면 카메라 목표면에서 CSS 기준 표시 반경을 보강한다. 큰 그래프의 밀도·색상·원래 물리 위치와 한 줄 상단을 유지한다. 세계 반경 상한과 점 중심 shader 때문에 모든 깊이에서 고정 시각 크기를 보장하지 않는다. 실제 렌더된 노드 수와 카메라·physics·transition 안정화를 구분해 네이티브 검수하고, 점 가독성을 의미 판정이나 성능 수치로 확대하지 않는다. [표시·검수 계약](../docs/architecture/alden-sparse-visibility-20261012.md).

## 0.3.75 — 자료 설명과 본문 근거

품질 정보 창에 내용 대신 자료 설명만 있는 현재 버전을 구분해 표시한다. 작은 창은 정보 창 내부를 스크롤하며 한 줄 상단을 유지한다. 정책v3·제품schema3에서 이전 모호한 결과나 누락 수량을 완료0으로 표시하지 않는다. 비교 카드에는 보관된 본문/저장 본문·설명/미열람 안내의 근거를 표시하고 메타데이터만으로 내용 묶기를 확인하지 않는다. 원래 노드·관계·벡터와 단정하지 않는 검토 후보를 유지한다. [보관 출처·실제 화면·독립 평가와 미결](../docs/architecture/alden-metadata-description-20261012.md).

## 0.3.74 — 집중 조회와 정확한 수집 시각

## 0.3.73 — 출처 비교와 가역 묶음

기억 정리의 기존 화면에 자료 찾기·비교·명시적 같은 지식 확인과 이중 되돌리기를 연결한다. 작은 창은 비교를 세로로 배치하고 내부 스크롤을 사용한다. 늦은 응답·선택 변경·결과를 놓친 요청의 재확인은 동일 요청과 검토 상태에 결속한다. 자료·관계 원본과 프로젝트·대상별 맥락은 유지하고, 묶음은 사용자의 가역 표시 결정으로 구분한다. 현재 출처 선언 정책v2와 검증된 본문을 비교하며 미열람 안내·잘린 비교만으로 확인하지 않는다. 한 줄 상단·기존 의미 배치와 그래프 전달4MiB상한을 유지한다. [네이티브 비교·복원·실제 읽기와 전달](../docs/architecture/alden-source-review-20261012.md).

## 0.3.72 — 본문 근거가 없는 기록 구분

수동 품질 정보에서 본문 텍스트 후보와 메타데이터 이름·미열람 안내의 일치를 구분한다. 선언된 제외 수량과 확인 범위를 표시하며 이전 모호한 보고서는 미확인으로 둔다. 의미 배치는 검증된 현재 투영·보관 기록의 미열람 선언도 확인하고 원래 노드·구조 관계를 보존한다. 한 줄 상단과 정보 창 내부 스크롤을 유지한다. [근거·실제 표본·설치와 미결](../docs/architecture/alden-source-content-evidence-20261012.md).

## 0.3.6 — sampled voice amplitude

The current graph and popover project recent microphone RMS into one 128-vertex orbital envelope. ## Motion model

Every activity input is clamped to `L ∈ [0, 1]`. For ring `i`,
`ωᵢ* = bᵢ (1 + gᵢ ℓᵢ) (1 + 0.35 L)`, where
`b = [0.17, -0.12, 0.09] rad/s`, `g = [1.4, 1.65, 1.9]`, and
`ℓ = [reply, GeekNews, DB sync]`. `L` is the maximum of job, background, and
voice activity; voice increases global motion but does not claim a ring. Ring
velocity follows the exact exponential damper
`ωᵢ ← ωᵢ + (ωᵢ* - ωᵢ)(1 - e⁻ᵏⁱᵈᵗ)`, with `k = [1.8, 2.35, 2.9] s⁻¹`.
Rotation integrates the preserved elapsed frame time, bounded at 250ms; nucleus
spring integration subdivides that time into steps of at most 50ms.

The lattice frequency is `f = 1 + 0.8L Hz`, amplitude is `0.05 + 0.05L`,
and opacity is `0.06 + 0.12L`. Its phase accumulates `φ ← (φ + 2πf·dt) mod 2π`
so changing load does not reset the waveform. A single 1,344-vertex sphere
buffer is packed into draw ranges of 448, 896, and 1,344 vertices; normalized
load thresholds 0.22 and 0.62 select the density. Frame updates only change the
draw range when the tier changes; they do not construct geometry.

## 관계·유사도 배치와 시각적 정지 — 0.3.54 및 0.3.55
