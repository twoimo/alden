# Alden app icon

`alden-app-icon-v1.png` is the original 1254 × 1254 transparent image generated with the built-in image generation tool on 2026-10-18. The user's request was for an Alden macOS app logo. No external logo or private runtime data was supplied.

The installed Tauri CLI converted this source into the PNG and multiresolution ICNS in `../src-tauri/icons/`. `tauri.conf.json` explicitly selects both new assets. The previous `icon.png` is retained.

Final generation prompt:

> Use case: logo-brand. Asset: one production macOS application icon for Alden, a calm personal AI knowledge-graph app. Design a distinctive minimal celestial letter A formed by 5 to 7 softly luminous silver-blue stars connected with a few precise thin strokes, one subtle lavender accent star; a crisp readable A silhouette, not a busy particle cloud. Center the mark on a deep midnight-navy rounded-square macOS icon tile with gentle restrained dimensional lighting and a tiny beveled rim. Sophisticated, quiet, friendly, high contrast and immediately legible at 32 pixels. Tile occupies about 82% of the square canvas with generous transparent padding outside the rounded square, centered and front facing. No text, no wordmark, no white frame, no extra symbols, no mockup, no surrounding scene. Keep all background outside the rounded icon tile truly transparent. Render a single square high-resolution icon.

This records the requested design constraints. Small-size readability is a visual review rather than an automated guarantee.
